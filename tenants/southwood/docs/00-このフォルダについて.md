# docs/ — 会社書類（southwood）

人が読む・印刷・提出する書類。数値正本は [`data/`](../data/)。

**Zone A（Core）** — 全組織共通。拡張（物件・VC 等）は **Zone B** — [tenant-document-zones.md](../../../steward/rules/tenant-document-zones.md)

## フォルダ一覧

| フォルダ | 用途 |
|----------|------|
| [company/](company/) | 法人 · 規程 · 議事録 · HR · 許認可 · 税務 · events |
| [contracts/](contracts/) | 契約書（CTR-XXX） |
| [procurement/](procurement/) | 調達 · **受領見積** · 発注書 |
| [sales/](sales/) | **提出見積** |
| [finance/accounting/](finance/accounting/) | 請求書 · 経理台帳 |
| [io/](io/) | 外部受領（inbox）· 送付控え（outbox） |
| [legal/](legal/) | 法務メモ |
| [compliance/](compliance/) | コンプライアンス |
| [executive/](executive/) | 秘書・役員 |
| [exports/](exports/) | CSV |
| [reports/](reports/) | CLI / Agent 生成 |

## 見積書の置き場所

| 状況 | パス |
|------|------|
| 相手からもらった見積（例: AIAC から） | `procurement/quotes/received/` |
| 自社が出した見積 | `sales/quotes/` |
