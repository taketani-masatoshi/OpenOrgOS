# 火災保険・企業総合保険 — 契約整理書（亀沢旅館）

> **契約ID:** CTR-014  
> **版:** v0.1（雛形・未加入）  
> **参考:** [千客不動産 — テナント火災保険請求実務](https://senkyaku.co.jp/columns/tenant-fire-insurance-claim-guide)、[アクア少額短期 — テナント保険](https://www.aqua-ins.com/plan/tenant.html)

---

## 1. 契約の性質

旅館・1棟貸しは **個人用火災保険では引き受け不可**。**企業総合保険・店舗総合** 等の設計が必要です。

| 項目 | 内容 |
|------|------|
| 被保険者 | 株式会社MAL |
| 物件 | 亀沢旅館（PROP-002） |
| 取得原価 | 96,000,000円（土地＋建物） |
| 用途 | 旅館業（1棟貸し・民泊型運営） |
| ステータス | **draft** |

---

## 2. 検討すべき補償一覧

| 補償 | 内容 | 優先度 |
|------|------|:------:|
| **火災・落雷・爆発** | 建物・内装・設備 | ◎ |
| **風災・ hail・水災** | 屋根・浸水 | ○ |
| **借家人賠償責任** | 土地所有者への賠償（該当時） | △ |
| **施設賠償責任** | **宿泊ゲストの怪我・物損** | ◎ |
| **什器備品** | 寝具・家電・内装 | ○ |
| **休業損害** | 火災後の収益ロス | △ |
| **盗難** | 備品 | △ |

---

## 3. 旅館 / 民泊の区分

保険商品は **用途（旅館業法 vs 民泊新法）** で引受条件が異なります。

- [ ] 旅館業許可の種別を保険会社に開示
- [ ] 1棟貸し・物理3室・最大8名の運営形態を説明
- [ ] OTA 経由予約（Airbnb / Booking）を明記

**民泊専用短期保険** と **旅館用企業総合** のどちらが適切か、代理店に設計依頼すること。

---

## 4. 施設賠償の目安

宿泊施設では、ゲストの **転倒・火傷・食中毒** 等に備える **施設賠償責任** が重要。

| 項目 | 目安 |
|------|------|
| 施設賠償 1事故あたり | **1,000万〜3,000万円** |
| 借家人賠償 | 建物評価額に応じ **1,000万〜2,000万円** |

参考: テナント保険商品では借家人賠・施設賠償 **各1,000万** セット例あり（[アクア](https://www.aqua-ins.com/plan/tenant.html)）。

---

## 5. 損害発生時フロー（要保管）

1. **速やかに** 保険会社・代理店へ連絡（多くは **30〜60日以内** 通知義務）
2. 現場写真・警察・消防の記録
3. ゲスト対応・OTA への報告（Airbnb ホスト保証等との関係整理）
4. 請求書類提出 → 保険金支払

---

## 6. オーナー（MAL）と建物の関係

亀沢は **自社所有（役員貸付調達）** のため「借家人賠償」より **所有建物の火災保険** が中心。

| パターン | 内容 |
|---------|------|
| 建物保険 | 96,000万円取得原価ベースで評価（実際は時価・再調達価額） |
| 施設賠償 | 宿泊業務の第三者賠償 |
