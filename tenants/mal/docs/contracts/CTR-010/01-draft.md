# Airbnb ホスト利用規約 — 契約整理書

> **契約ID:** CTR-010  
> **版:** v0.1（2026-06調査）  
> **種別:** プラットフォーム規約（個別交渉契約ではない）

---

## 1. 契約の性質

Airbnb へのホスト登録・リスティング作成は、**サービス利用規約（Terms of Service）への同意**により成立します。株式会社MAL と Airbnb との間で個別に条文を交渉する契約ではなく、**規約＋ホスト規約（第4〜7条等）** が適用されます。

| 項目 | 内容 |
|------|------|
| 契約相手 | Airbnb（日本ホスト: **Airbnb Ireland UC** 等 — 付属文書1参照） |
| 物件 | 亀沢旅館（PROP-002） |
| 想定開始 | 2026年8月（開業） |

## 3. 手数料（2025年末〜の単一手数料モデル）

Web調査・当社費用計画との整合:

| 項目 | 内容 |
|------|------|
| ホスト手数料 | **予約総額（税抜）の 15.5%**（2025年12月1日頃〜全ホスト統一） |
| 課金対象 | 宿泊料金 **＋ 清掃料 ＋ 追加ゲスト料 ＋ ペット料** 等 |
| ゲスト側 | サービス料は表示されにくいモデル（ホスト側で実質負担） |
| 当社計上 | `PROP-002` operating_costs `ota_commission_rate: 0.155` |

参考: [Arch — Airbnb 15.5% 解説](https://archcorp.jp/columns/airbnb-host-fee-15-5-percent-2025/)

**受取額維持の目安:** 旧3%モデルからの移行では、表示価格を約 **+14〜18%** 調整する事例が多い。

---

## 4. ホストの主な義務（規約要約）

1. **正確なリスティング** — 住所・定員・設備・ハウスルール
2. **法令遵守** — **旅館業法**・消防法・自治体条例（届出番号の掲載）
3. **税金** — 宿泊税・消費税の申告（規約第7条「税金」）
4. **キャンセルポリシー** — 選択したポリシーに従う
5. **オフプラットフォーム誘導禁止** — 直接予約への誘導は規約違反でアカウント停止リスク
6. **保険・安全** — スモーク・CO検知器等の推奨要件を確認

---

## 5. MAL が登録前に確認すること

- [ ] 旅館業許可・届出番号
- [ ] リスティング住所（墨田区亀沢1）
- [ ] キャンセルポリシー（厳しめ vs 柔軟）
- [ ] 清掃料の設定（手数料15.5%の対象になる点に注意）
- [ ] ホストアカウント管理者（段・宮城）
- [ ] 規約同意日の記録
