# Booking.com 宿泊パートナー契約 — 契約整理書

> **契約ID:** CTR-011  
> **版:** v0.1（2026-06調査）  
> **種別:** パートナー契約（Partner Agreement）＋ 利用規約

---

## 1. 契約の性質

Booking.com への施設登録は、**Booking.com B.V.**（オランダ）との間で、**パートナー利用規約・手数料条件**に同意して成立します。個別の日本語契約書を郵送する形式ではなく、**Extranet 上の契約フロー**が本体です。

| 項目 | 内容 |
|------|------|
| 契約相手 | **Booking.com B.V.** |
| 物件 | 亀沢旅館（PROP-002） |
| 掲載料 | **無料**（成果報酬型） |

---

## 2. 手数料（調査結果）

| 項目 | 内容 |
|------|------|
| 基本モデル | **予約成立時のみ**手数料（掲載無料） |
| 日本の目安 | **12〜15%**（宿泊料金・税抜ベース） |
| 変動要因 | 物件タイプ・地域・**Genius プログラム**・Visibility Booster（+10〜30%） |
| 確定方法 | 登録後の **Partner Agreement / Extranet** に記載 |

参考:
- [民泊OL — Booking.com 登録・手数料](https://minpaku-mlit.jp/booking-registration/)
- [9STAY — 手数料体系](https://9stay.net/column/224)

**Airbnb との比較（2026年時点）:**

| | Airbnb | Booking.com |
|---|--------|---------------|
| ホスト手数料目安 | **15.5%**（単一モデル） | **12〜15%** |
| ゲスト層 | 訪日・中長期多め | 欧米・短期多め |
| 支払い | Airbnb経由決済 | 事前決済 / 現地決済（設定次第） |

参考: [民泊学校 Airbnb vs Booking 2026](https://minpakugakko.com/airbnb-vs-booking-com-2026/)

---

## 3. 登録・運用上の注意

1. **審査** — 物件認証・民泊/旅館届出番号確認に **数日〜数週間**
2. **決済設定** — 初期「現地決済」だと「事前決済」への変更に **数ヶ月** かかる事例あり → **最初から事前決済推奨**
3. **キャンセル料** — ゲストにキャンセル料を請求し**受け取らなければ**手数料なし。受け取った場合は手数料対象
4. **他サイト掲載** — チャネルマネージャー併用時は料金 parity 要確認
5. **メッセージ機能** — キャンセル率低減に活用
