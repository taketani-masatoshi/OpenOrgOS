# オフィス賃貸借契約書（本社区画 · サウスウッド）

> **契約ID:** CTR-012  
> **版:** v1.0（締結済）  
> **貸主:** 株式会社 MAL · **借主:** 株式会社サウスウッド

---

株式会社 MAL（以下「**甲**」という。）と、株式会社サウスウッド（以下「**乙**」という。）とは、甲が所有・管理するオフィス区画を乙に賃貸し、乙がこれを借り受けることについて、以下のとおり賃貸借契約（以下「**本契約**」という。）を締結する。

## 第1条（目的物件）

| 項目 | 内容 |
|------|------|
| 所在地 | 東京都千代田区二番町1（MAL 本社ビル内） |
| 区画 | 約 15 ㎡（デスク4席・収納付き） |
| 用途 | 事務所（乙の本店登記外利用は要甲承諾） |

## 第2条（賃料等）

| 項目 | 内容 |
|------|------|
| 月額賃料 | **85,000 円**（税別） |
| 共益費 | 賃料に含む |
| 支払期日 | 毎月末締め、**翌月25日** 振込 |
| 敷金・礼金 | 別紙覚書（L1 サマリのみ · 口座は broker 経由） |

## 第3条（契約期間）

| 項目 | 内容 |
|------|------|
| 開始日 | 2026年4月1日 |
| 期間 | 1年（自動更新 · 更新前60日前まで書面解約可） |

## 第4条（原状回復・禁止事項）

乙は契約終了時、通常損耗を除き原状回復する。転貸・権利譲渡は甲の書面承諾を要する。

## 第5条（準拠法）

日本法 · 管轄: 東京地方裁判所
