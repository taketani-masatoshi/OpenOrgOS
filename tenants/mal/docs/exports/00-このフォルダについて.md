# 計画データ（CSV）

数値のみ。正データは `data/plans/*.yaml`（YAML のみ）。

| CSV | 対応 YAML |
|-----|-----------|
| [売上計画.csv](売上計画.csv) | `data/plans/revenue-plan.yaml` |
| [利益計画.csv](利益計画.csv) | `data/plans/profit-plan.yaml` |
| [費用計画.csv](費用計画.csv) | `data/plans/expense-plan.yaml` |
| [投資計画.csv](投資計画.csv) | `data/plans/investment-plan.yaml` |
| [契約管理表.csv](契約管理表.csv) | `data/contracts/*.yaml` |
| [shareholder-register.csv](shareholder-register.csv) | [`shareholder-register.md`](../company/shareholder-register.md)（手動同期） |

契約書本文は [`docs/contracts/`](../contracts/) を参照。

YAML を更新したら CSV も同期してください。

```bash
npm run steward -- sync all      # 全 CSV を YAML から再生成
npm run steward -- sync contracts # 契約管理表のみ
```
