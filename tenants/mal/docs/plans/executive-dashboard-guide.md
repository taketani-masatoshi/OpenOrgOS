# 経営ダッシュボード KPI 定義

オーナー向け日次ダッシュボード（`steward dashboard`）で表示する指標の定義と読み方。

---

## 更新頻度

- **1日1回** — `npm run orgos -- dashboard` を実行
- 出力: `docs/reports/dashboard/YYYY-MM-DD.md`（日付ファイルで上書き防止）

---

## キャッシュフロー指標

黒字運転（キャッシュ増）と赤字運転（キャッシュ消耗）で **表示用語を切り替える**。

| 状態 | 資金見通し KPI | 月次 CF KPI | 算式 |
|------|---------------|-------------|------|
| **黒字**（収入 > 支出） | **資金見通し** | **月次キャッシュ増** | 3ヶ月増見込 = 月次増 × 3 · 目標到達 = (1,000万 − 残高) ÷ 月次増 |
| **赤字**（支出 > 収入） | **ランウェイ** | **ネットバーン** | ランウェイ = 残高 ÷ ネットバーン |
| **均衡** | ランウェイ（収支均衡） | 月次ネットCF | — |

| KPI | 算式 | データソース | 備考 |
|-----|------|-------------|------|
| **資金見通し**（黒字時） | 3ヶ月キャッシュ増 · 目標1,000万円までの月数 | 月次実績/計画 + `cash-balance.yaml` | 残高未登録時は3ヶ月増のみ表示 |
| **ランウェイ**（赤字時） | 現預金残高 ÷ 月次ネットバーン | 残高 TBD | 残高未登録時は算出不可 |
| **月次キャッシュ増** | 収入 − 支出 − 返済 | 月次実績 or 計画 | 黒字運転時のみ |
| **ネットバーン** | 支出（返済含む）− 収入 | 月次実績 or 計画 | 赤字運転時のみ（正=流出） |
| **月次売上** | 収入合計 | `finances/monthly/` or 予実 | ベース月をダッシュボードに表示 |
| **月次利益** | 売上 − 経費 − 借入返済 | 同上 | 営業利益の近似（減価償却含む） |
| **固定費** | 本社固定費 + 減価償却 + 借入返済 | `fixed-costs.yaml` + `expense-plan` + `loans` | 売上に連動しない部分 |
| **変動費** | 物件運営費・管理手数料等 | `property-revenue` + 予実 | 売上連動の見込み |
| **損益分岐売上** | 固定費 ÷ 限界利益率 | 上記から算出 | 限界利益率 = (売上−変動費)/売上 |

### 限界利益率（貢献利益率）

賃貸・旅館の混合事業では、計画ベースの売上と変動費から全体の限界利益率を算出する。

```
限界利益率 = (月次売上 − 月次変動費) / 月次売上
損益分岐売上 = 月次固定費 / 限界利益率
```

亀沢旅館は稼働率・ADR に連動、番町ハイムは主に固定賃料収入。

## タスク優先度

| 区分 | 条件 |
|------|------|
| **高重要度** | 保険 draft（CTR-013/014）、high リスク契約、資金計画 TBD |
| **高緊急度** | 契約期限 30 日以内、high リスクアラート、Inbox 未処理 |

アラートは `steward alerts` と同一ロジック（`src/lib/alerts.ts`）。

## 月次トレンドの読み方

予実 YAML（`data/plans/yojitsu-fy*.yaml`）の月次行から:

1. **開業前** — 番町賃料のみ、設備投資（capex）集中月は単月赤字が計画内
2. **開業後** — 亀沢売上加算、運営費（変動費）発生
3. **前月比** — 直近稼働月の売上・純増減をナラティブで要約

### ナラティブテンプレート（月次レビュー用）

```
【{月}】売上 {金額} / 支出 {金額} / 純増減 {金額}
・前月比: {増減}（要因: {稼働率/空室/capex/一時費用}）
・計画比: {予実差} — {コメント}
・翌月フォーカス: {アクション1件}
```

## 次の支払い

`steward dashboard` の **次の支払い** セクション。経営者が直近のキャッシュアウトを把握するための一覧。

| 区分 | 内容 | データソース | 備考 |
|------|------|-------------|------|
| **固定費（月次）** | `monthly_amount` 項目 | `fixed-costs.yaml` | 各月末日を支払期限として 90 日以内を列挙 |
| **固定費（年次）** | `annual_amount` のみの項目 | `fixed-costs.yaml` | 会計年度末を期限目安（支払日は要確認） |
| **給与** | 役員報酬（年額 ÷ 12） | `payroll.yaml` | 年額 0 の場合は非表示 |
| **借入返済** | base シナリオの元本返済 | `debt-plan.yaml` | 当年度分 + 90 日以内に年度末が来る分。当年度 0 円の場合は注記行 |
| **契約** | 更新・保険 draft 期限 | `alerts.ts` → tasks | 金額は契約条項参照（— 表示） |

支払日は YAML に明示されないため **月末日 / 年度末** を目安とする。確定日は Finance Agent · 月次決算 Skill で補完。
