# DSCR 管理計画

**版:** 2026-06-07 · **正データ:** [`data/plans/debt-plan.yaml`](../../../data/plans/debt-plan.yaml)

## 目的

返済余力（DSCR: Debt Service Coverage Ratio）を監視し、任意返済のペース判断と Executive への早期警告を行う。現行は銀行借入なしのため **内部管理 KPI** であり、金融機関 covenant ではない。

## 定義

```
DSCR = NOI（代理） ÷ 年間元本返済額（debt service）
```

| 要素 | 本社での扱い |
|------|-------------|
| NOI 代理 | `profit-plan.yaml` の **operating_profit**（全社営業利益） |
| debt service | **元本返済のみ**（無利息のため利息なし） |
| 返済ゼロ年 | DSCR = N/A（十分な余力とみなす） |

## 管理目標

| レベル | DSCR | アクション |
|--------|-----:|-----------|
| 目標 | **≥ 1.2** | 計画通り返済可 |
| 警告 | 1.0 – 1.2 | 返済ペース見直しを Finance → Executive 報告 |
| 危険 | **< 1.0** | 保守シナリオ採用 · 返済延期協議 · コスト/収益改善 |

## 示唆

1. **基本シナリオ**では FY2030（LOAN-002 返済開始）以降、横ばい営業利益前提で DSCR 1.2 を下回る。
2. **対応案:** 保守シナリオ採用 · 基本シナリオの年次返済額引下げ · 営業利益成長（稼働率・ADR 改善） · 期限前の平準化返済。
3. 無利息・役員貸付のため、**協議による返済延期**も選択肢（契約 TBD 確認要）。
