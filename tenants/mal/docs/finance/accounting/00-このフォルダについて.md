## 運用

1. 支出発生 → [REG-005 経費精算規程](../../company/regulations/keihi-seisan-kisoku.md) に従い承認
2. 経費精算台帳に記入 → 領収書は `records/receipts/{年}/` にスキャン保管（Git 非推跡）
3. 月次: `data/finance/monthly/` YAML と照合
4. 決算: 税理士へ `orgos ledger trial-balance` 出力 + CSV records + 領収書を提出
