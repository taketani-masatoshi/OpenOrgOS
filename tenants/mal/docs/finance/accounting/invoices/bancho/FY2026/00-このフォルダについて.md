# 番町ハイム312 請求書（FY2026）

PROP-001 · CTR-003 賃貸借に基づく月次賃料請求の生成物です。

---

## 生成コマンド

```bash
npm run orgos -- invoice bancho --from 2026-02 --to 2027-01
```

| オプション | 説明 |
|-----------|------|
| `--from` / `--to` | 請求対象月（YYYY-MM） |
| `--fy` | 出力フォルダ（既定: FY2026） |
| `--tenant-name` | 借主名（未指定時はプレースホルダ） |
| `--tenant-email` | 送付先メール |
| `--bank-account` | 振込先口座 |

実装: `src/lib/invoice-pdf.ts` · `src/lib/invoice-email.ts` · `src/commands/invoice.ts`

## MSG / EML について

| 形式 | 可否 | 備考 |
|------|------|------|
| **.eml** | ✅ | 標準 MIME。Outlook・Apple Mail で開ける |
| **.msg** | ✅（生成可） | `@independentsoft/msg` 使用。**評価版ライセンス**のため本番運用は .eml 推奨 |

Mac でも .msg ファイルは生成できます。Outlook for Mac で開いて送信するか、.eml を利用してください。

## 請求仕様

- 月額賃料: **100,000円**（PROP-001）
- 請求番号: `INV-BANCHO-YYYY-MM`
- 発行日: 請求対象月の末日（月末締め）
- 支払期限: 翌月末（CTR-003: 毎月末締め翌月払い）
- 消費税: 非課税表示（貸付用家屋・**要税理士確認**）
- インボイス: T4010001189530
