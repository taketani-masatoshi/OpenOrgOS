# accounting/records — 記入済み会計台帳（Git 非追跡）

**方針:** 外部会計 SaaS **非導入**。Accounting Agent が CSV を人間可読ミラーとして維持し、**正本は `data/finance/*.yaml`**。

| ファイル | 正本 YAML | 用途 |
|----------|-----------|------|
| 現金出納帳.csv | bank-statements.yaml · cash-balance.yaml | 入出金一覧 |
| 経費精算台帳.csv | expense-claims.yaml | 承認済経費 |
| 領収書索引.csv | document-io.yaml | 証憑所在 |
| 固定資産台帳.csv | fixed-assets.yaml | 減価償却 |
| 仕訳一覧.csv | journal-entries.yaml | `orgos ledger export` |
| 試算表.csv | （仕訳から派生） | `orgos ledger export --template trial-balance-csv` |

運用手順: [file-based-accounting-runbook.md](../file-based-accounting-runbook.md)

**実取引:** STAY-2026-001 · ECL-20260803-001 連携済（2026-08-24）。
