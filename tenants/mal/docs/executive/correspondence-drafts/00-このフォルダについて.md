# correspondence-drafts — 承認待ち下書き

**Owner:** Secretary · **Git:** 非追跡（実ファイル）· **追跡可:** `*.example.md` のみ

Secretary が生成する社外招待・調整の下書き MD。氏名・メール文面を含むため Git には載せない。

## 運用

1. Secretary が `YYYY-MM-DD-{slug}.md` を本フォルダに生成（ローカル · gitignore）
2. 段が内容を確認 → Calendar / Gmail で送信
3. 送信後、Secretary が `data/executive/calendar.yaml` を更新

雛形: [correspondence-draft-template.md](../correspondence-draft-template.md) · 示例: [2026-06-01-sample-mtg-invite.example.md](2026-06-01-sample-mtg-invite.example.md)
