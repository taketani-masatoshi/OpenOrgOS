# correspondence-drafts — 承認待ち下書き

**Owner:** Secretary · **Git:** 非追跡（実ファイル）· **追跡可:** `*.example.md` のみ

Secretary が生成する社外招待・調整の下書き MD。氏名・メール文面を含むため Git には載せない。

## 運用

1. Secretary が `DRAFT-*.yaml` + MD を本フォルダに生成（`secretary correspondence draft`）
2. `org approval approve` で人間承認
3. `secretary correspondence send --id DRAFT-...` で SMTP / dry_run 送信
4. 送信後、会社イベント記録 · 必要なら `calendar.yaml` 更新

**自動送信禁止** — 承認ゲート必須。
