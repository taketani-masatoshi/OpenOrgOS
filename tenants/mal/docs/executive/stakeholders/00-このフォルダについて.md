# 利害関係者プロフィール（Stakeholder Profiles）

**機密ゾーン:** 本フォルダの実ファイルは **Git 非追跡**（GitHub 等に push されません）。

---

## 目的

Secretary · Contract · Operations 等の Agent が、社外の **氏名・会社・Web・バックグラウンド・連絡時の注意** を参照するためのプロフィール置き場。

| 層 | パス | Git |
|----|------|-----|
| **索引（SoT）** | [`data/executive/stakeholders.yaml`](../../../data/executive/stakeholders.yaml) | **非追跡** |
| **テンプレート** | [`data/executive/stakeholders.yaml.example`](../../../data/executive/stakeholders.yaml.example) | 追跡 |
| **プロフィール MD** | 本フォルダ `STK-*.md` | **非追跡** |
| **例（構造のみ）** | `*.example.md` | 追跡 |

---

## 初回セットアップ

```bash
cp data/executive/stakeholders.yaml.example data/executive/stakeholders.yaml
cp docs/executive/stakeholders/STK-001-taketani.example.md docs/executive/stakeholders/STK-001-taketani.md
cp docs/executive/stakeholders/STK-003-southwood.example.md docs/executive/stakeholders/STK-003-southwood.md
cp docs/executive/stakeholders/STK-004-nihon-jutaku.example.md docs/executive/stakeholders/STK-004-nihon-jutaku.md
# 連絡先等を編集
npm run validate
```

---

## 機密レベル

| レベル | 本フォルダに書いてよい | 例 |
|--------|------------------------|-----|
| **L0** | 会社名 · 公式 URL · 公開経歴 | org · website · バックグラウンド |
| **L1** | ビジネスメール · 業務用 Chat | `contact.email` · profile 内 |
| **L2** | 個人携帯 · 自宅住所 | **`records/`（別 gitignore）** — 本 MD には書かない |

契約書に既にある住所は **CTR YAML / docs/contracts/** が SoT。プロフィールに重複記載しない。

---

## Agent アクセス

| Agent | 権限 |
|-------|------|
| **Secretary** | 索引 + プロフィール Read/Write |
| **Contract** | `contract_ids` に紐づく STK Read |
| **Operations** | `outsourcing` / `vendor` タグ Read |
| **Executive Steward** | 要約のみ（フルプロフィール直読しない） |

索引: [`data/executive/external-contacts.yaml`](../../../data/executive/external-contacts.yaml) の `stakeholder_id` と対応。
