## Fire / 火災

1. Alert others · shout **Kaji da!** (Fire!)
2. Call **119**
3. Evacuate — do not use elevator if present
4. **Extinguisher:** near entrance / 玄関付近 TBD
5. Contact host

**Assembly point / 集合:** Safe spot on the street in front of the house / 建物前の道路

---

## Earthquake / 地震

- During shaking: cover head, stay away from falling objects
- After: check fire sources (gas stove), open exit route
- Sumida is inland — follow official tsunami info if any
