## 近隣への配慮

## ゴミ

**道端・集積所に置かないでください**（条例違反・近隣トラブルの原因になります）。

1. **キッチンの分別袋・ゴミ箱** を使用
2. **燃やすごみ** / **燃やさないごみ** / **資源（ペットボトル・缶・びん）** に分ける
3. **チェックアウト時:** 分別済みのゴミはキッチン内のみ — 持ち出し不要
4. **粗大ごみ:** 連絡ください — 置き去り禁止

回収は当館側で行います。
