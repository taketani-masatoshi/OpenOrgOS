# 宿泊者名簿 運用規則

**文書ID:** OPS-LODGE-001  
**版:** v1.0  
**制定:** 2026年6月6日  
**関連:** 旅館業法第6条、REG-010、REG-012

---

## 第1条（目的）

亀沢旅館における **宿泊者名簿** の作成、保管、外国人届出、個人情報管理を定める。

## 第2条（記録義務）

旅館業法に基づき、宿泊者について次を **記録** する。

1. 氏名、住所、職業、年齢、性別
2. 国籍及び外国籍者の **旅券番号** その他の身分証明書番号
3. 入室日・退室日
4. 連絡先（取得できる場合）

## 第3条（記録方法）

1. 様式: [templates/compliance/宿泊者名簿.csv](templates/compliance/宿泊者名簿.csv)
2. 保存: `lodging/records/{年}/compliance/宿泊者名簿-{年}.csv`（又は月次ファイル）
3. OTA 予約情報を **チェックイン時** に転記又は確認する
4. 電磁的記録可。改ざん防止のため **追記型** とし、削除は REG-010 の削除手順に従う

## 第4条（チェックイン手順）

1. [宿泊者向け告知](../../../../compliance/privacy/guest-privacy-notice.md) を提示
2. 本人確認（旅券・運転免許等）
3. 名簿へ記入（代表者1名 + 全宿泊者氏名を推奨）
4. 外国籍: 第5条へ

## 第5条（外国人宿泊者届）

1. 外国籍で国内に住所を有しない宿泊者は、 **24時間以内** に所轄警察署へ届出（旅館業法第6条第2項）
2. 届出記録: [templates/compliance/外国人宿泊者届.csv](templates/compliance/外国人宿泊者届.csv)
3. パスポート **画像** は届出用に一時保管。保管場所は Git 外の暗号化媒体
4. オンライン届出（e 届出等）を利用する場合も、控えを `records/` に保存

## 第6条（アクセス・保管）

| 項目 | ルール |
|------|--------|
| 閲覧権限 | 代表取締役2名、清掃委託先には **渡さない** |
| 保管期間 | 退室後 **5年**（REG-010。税務・調査で延長可） |
| バックアップ | 月1回、暗号化 |
| Git | **禁止**（records/ は gitignore） |

## 第7条（削除）

保管期間経過後、復元不能な方法で削除し、削除日を内部メモに残す。

## 第8条（改定）

改定は取締役会又は REG-012 に従う。
