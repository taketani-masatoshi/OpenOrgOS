## 1. 運用の前提

| 項目 | 内容 |
|------|------|
| チェックイン | 基本 **セルフ**（スマートロック）。必要時のみ対面 |
| 予約チャネル | Airbnb（CTR-010）・Booking（CTR-011） |
| 清掃 | 委託（CTR-012）。CO 後 **4〜6時間以内** 完了 |
| 担当 | 代表取締役2名（フロント常駐なし） |
| 緊急 | [REG-013](../../../company/regulations/jigyo-keizoku-kisoku.md) · [緊急時案内](templates/guest-facing/緊急時連絡・避難.md) |

## 2. 予約〜滞在〜退室（1件あたり）

```
[予約確定]
  ① 予約稼働台帳に追記
  ② OTA 自動メッセージ + 必要なら [チェックイン案内](templates/guest-facing/チェックイン案内.md) 送信
  ③ 清掃業者へ [清掃発注引継](templates/housekeeping/清掃発注引継.csv)（前泊 CO 日が分かれば先行連絡）

[CI 当日]
  ④ 施設最終確認（前泊清掃完了・鍵・消耗品）
  ⑤ ゲストへ鍵コード / アクセス案内
  ⑥ チェックイン確認 + 宿泊者名簿記入 + 告知文
  ⑦ 外国籍 → 旅券確認 → 24h 以内届出

[滞在中]
  ⑧ 問合せ対応（24h 以内初動）
  ⑨ トラブル → 故障報告 / クレーム記録

[CO 当日]
  ⑩ チェックアウト確認（鍵・ゴミ・設備）
  ⑪ 名簿に退室日、清掃発注
  ⑫ 清掃完了報告受領 → 清掃記録
  ⑬ レビュー依頼（任意）[OTAメッセージ](templates/messages/OTAメッセージテンプレート.md)
```

## 3. 日次ルーティン（営業日）

| 時刻目安 | 作業 | 様式 |
|---------|------|------|
| 朝 | 当日 CI/CO 確認、OTA メッセージ確認 | [日次運営記録](templates/operations/日次運営記録.csv) |
| 随時 | ゲスト対応、清掃状況確認 | 清掃発注引継 |
| CO 後 | 清掃完了待ち、次泊準備 | 清掃記録 |
| 夜 | 翌日予約確認、日次締め | 日次運営記録 |

**宿泊なしの日:** 日次記録に「稼働なし」と1行記入（空白日を残さない）。

## 4. 週次・月次

| 頻度 | 作業 | 様式 |

| 四半期 | ハウスルール・案内文の見直し | guest-facing/ |
