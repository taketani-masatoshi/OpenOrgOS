## 初回セットアップ

1. `records/2026/` 以下に `rental/` · `compliance/` を作成
2. 各 CSV を **年次ファイル** としてコピー（例: `rental/賃料入金確認-2026.csv`）
3. CTR-003 の借主名・連絡先を請求 CLI オプションに反映
4. CTR-013 火災保険加入後、証券を `records/compliance/` に保管（gitignore）
