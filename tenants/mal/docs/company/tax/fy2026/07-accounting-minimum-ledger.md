# 第9期 会計帳簿 — 法人決算の最低限整備

**株式会社MAL · 第9期（2026/2/1〜2027/1/31）**  
**目的:** 貸借対照表（B/S）作成と法人税申告の前提となる **帳簿の最低ライン** を整理する。

> 本書は [国税庁・中小企業支援資料](https://j-net21.smrj.go.jp/startup/manual/list8/8-3-7.html)、[マネーフォワード 主要簿解説](https://biz.moneyforward.com/accounting/basic/92/) 等に基づく **読み物版** です。実務は税理士・会計ソフトで確定してください。

---

## 1. なぜ複式簿記か

法人は **会社法・法人税法** により会計帳簿の作成が義務付けられています。貸借対照表を作成するには **複式簿記** が必要です。

| 段階 | 内容 |
|------|------|
| 期中 | 取引を仕訳 → 総勘定元帳へ転記 |
| 決算 | 減価償却・期間損益の修正（決算整理仕訳） |
| 出力 | 貸借対照表・損益計算書・勘定科目内訳明細書 |

## 2. 最低限そろえる帳簿

| 帳簿 | 必須度 | Steward での対応 | 保存期間 |
|------|:------:|-----------------|:--------:|
| **仕訳帳**（仕訳伝票） | **必須** | `journal-entries.yaml` + `orgos ledger` | 法人 **10年** |
| **総勘定元帳** | **必須** | `orgos ledger gl` | 10年 |
| 現金出納帳 | 推奨 | 銀行明細 + [`cash-balance.yaml`](../../../../data/finance/cash-balance.yaml) | 10年 |
| 固定資産台帳 | 推奨 | PROP-001/002 + keisansyorui 減価償却試算 | 10年 |
| 売掛・買掛帳 | 該当時 | OTA 入金・業者支払は月次 YAML | 10年 |
| 領収書・請求書 | 立証 | inbox / receipts | 7〜10年 |

**三大原則:** 網羅性（全取引記録）· 立証性（証憑に基づく）· 秩序性（時系列・科目別）

## 5. 電子帳簿保存・優良要件（参考）

法人税申告書付表「帳簿類の備付状況」では、電子保存の有無を記載します。会計ソフト利用時は **検索・出力・改ざん防止** が要件（[国税庁 記載要領](https://www.nta.go.jp/publication/pamph/pdf/0023002-059.pdf)）。

| 項目 | MAL 現状 |
|------|---------|
| 会計ソフト | **非導入** — OrgOS GL（`journal-entries.yaml` + `orgos ledger`）+ CSV ミラー |
| Steward YAML | 経営分析・仕訳正本（申告 XML には直結しない） |
| 証憑 PDF | `docs/io/inbox/` · `licenses/records/` |
