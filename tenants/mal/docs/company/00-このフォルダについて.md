- 本フォルダの書類は **予想ベース・簡易版** です。税理士確認後に確定版へ更新してください。
- **TBD（要入力）** 項目: 株主住所、第9期末現金残高、累計減価償却（税理士突合）

- PDF: `npm run orgos -- report kessan --fy FY2025`（第8期）· `report annual --fy FY2026`（第9期）

## 更新ルール

1. 数値変更 → 先に `data/` の YAML を更新 → `npm run validate`
2. 決算確定後 → 本フォルダの MD を更新 → PDF を再生成
3. 署名欄は印刷後に手書き署名
