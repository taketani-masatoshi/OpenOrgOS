# 個人情報保護規程

**株式会社MAL**  
**規程ID:** REG-010  
**版:** v1.0（制定）  
**制定日:** 2026年6月6日（取締役会決議）  
**関連:** 個人情報保護法、ISO/IEC 27001、ISO 21401

---

## 第1条（目的）

本規程は、個人情報の適正な取得・利用・保管・提供・削除を定め、本人の権利を保護するとともに、ゲスト・取引先・役員等の信頼を確保する。

## 第2条（定義）

1. **個人情報:** 個人情報保護法第2条に定める個人情報。
2. **個人データ:** 個人情報データベース等を構成する個人情報。
3. **保有個人データ:** 会社が開示等の請求に応じるべき個人データ。
4. **要配慮個人情報:** 人種、信条、病歴等（原則取得禁止）。

## 第3条（適用範囲）

次の業務で扱う個人情報に適用する。

| 業務 | 例 |
|------|-----|
| 亀沢旅館 | ゲスト氏名、連絡先、パスポート情報、決済情報 |
| OTA | Airbnb・Booking 経由の予約者情報 |
| 翻訳・SES | 取引先担当者、原稿に含まれる個人名 |
| 経営 | 役員・株主・委託先担当者 |

## 第4条（利用目的）

個人情報は、取得時に示した目的の範囲内で利用する。

| 区分 | 利用目的 |
|------|---------|
| ゲスト | 宿泊契約の履行、本人確認、緊急連絡、法令に基づく届出 |
| 取引先 | 契約履行、請求、品質管理、問合せ対応 |
| 委託先 | 契約管理、支払、業務連絡 |
| 採用（将来） | 選考、雇用管理 |

目的外利用を行う場合は、法令に従い必要な措置を講じる。

## 第5条（取得・同意）

1. 利用目的を **できる限り明示** した上で取得する。
2. OTA 経由の情報は、各プラットフォームの規約及びプライバシーポリシーに従う。
3. 要配慮個人情報は、原則取得しない。

## 第6条（安全管理措置）

[情報セキュリティ管理規程](joho-security-kanri-kisoku.md) に従い、次を実施する。

1. アクセス権限の制限、MFA、端末暗号化
2. 個人データの **最小保管**（不要データの定期削除）
3. 委託先への提供時は、契約で安全管理を義務付ける
4. 持ち出し・持ち込み端末の管理

## 第7条（第三者提供・委託）

1. 本人の同意又は法令に基づく場合を除き、第三者に提供しない。
2. 清掃・PMS・決済等へ委託する場合は、委託先を選定し、契約で監督する。
3. 外国にある第三者への提供は、法令に従い必要な情報を提供する。

## 第8条（漏えい等への対応）

1. 漏えい、滅失、毀損のおそれがある場合は、速やかに [REG-009](joho-security-kanri-kisoku.md) のインシデント手順を開始する。
2. 個人データの漏えい等が個人の権利利益を害するおそれがある場合は、**速やかに** 個人情報保護委員会への報告及び本人への通知を検討する。
3. 記録を **3年** 保管する。

## 第9条（開示・訂正等）

本人から保有個人データの開示、訂正、利用停止、消去等の請求があった場合、法令に従い **遅滞なく** 対応する。  
請求窓口: **info@malkk.com**（代表取締役が対応）

## 第10条（保管・削除）

| データ | 保管場所 | 保管期間 |
|--------|---------|---------|
| ゲスト台帳・予約記録 | [`docs/properties/PROP-002-kamezawa/operations/records/`](../../properties/PROP-002-kamezawa/operations/records/) | 宿泊終了後 **5年** |
| 取引先担当者 | 案件・契約フォルダ | 取引終了後 **5年** |
| インシデント記録 | [`docs/compliance/privacy/records/`](../../operations/privacy/records/) | **3年** |
| 雇用関連 | [`docs/company/hr/records/`](../../operations/hr/records/) | 労基法に従う |

記入済みデータは **Git に含めない**（`.gitignore`）。  
保管期間経過後は、復元不能な方法で削除する。

## 第11条（改定）

本規程の改定は、取締役会の決議による。
