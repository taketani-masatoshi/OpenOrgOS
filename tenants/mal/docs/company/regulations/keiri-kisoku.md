# 経理規程（雛形）

**規程ID:** REG-027  
**版:** v1.2（テンプレート）  
**例示: 株式会社MAL

---

## 第1条（目的）

本規程は、当社の会計処理の基本方針、帳簿組織、月次・年次の決算手続、証憑の保管及び経理に関する内部統制の要点を定め、経理業務の適正かつ統一した運用を確保する。

## 第2条（適用範囲）

1. 本規程は、当社のすべての会計・経理業務に適用する。
2. 経費の申請・精算は経費精算規程、支出・契約の決裁は稟議・決裁規程、旅費は旅費規程、法人カードはクレジットカード規程、資金・口座・支払は本規程第8条、税務申告の準備手続は各税務関連規程と併用する。

## 第3条（定義）

本規程において、次の各号に掲げる用語の意義は、当該各号に定めるところによる。

1. **仕訳正本** — 当社が取引を記録する会計上の正本帳簿（電子記録を含む）
2. **証憑** — 請求書、領収書、契約書、預金通帳写しその他取引の事実を証明する資料
3. **月次締め** — 各月の記帳を完了し、残高・主要科目の突合を行った状態を確定する手続
4. **決算** — 事業年度末における計算書類等の作成に至る一連の手続
5. **税理士等** — 税理士、公認会計士その他当社が委任する外部の税務・会計専門家

## 第4条（会計処理の原則）

1. 会計処理は、日本において一般に公正妥当と認められる企業会計の基準に従う。
2. 記帳は **発生主義** を原則とする。現金主義による処理が法令上認められる場合を除き、これを用いてはならない。
3. 会計年度は定款に定める事業年度に一致させる。
4. 勘定科目の体系及び名称は、取締役会又は代表取締役が定める勘定科目表による。

## 第5条（帳簿・伝票）

1. 仕訳、総勘定元帳及び必要な補助簿は、仕訳正本として一体管理する。会計ソフトその他の外部システムを併用する場合は、同期の責任者及び頻度を別紙1に定める。
2. 取引が発生したときは、遅滞なく仕訳正本に記録する。
3. 証憑は法令及び文書管理規程に従い保管する。保管年数の目安は別紙2による（法人税法その他の法令の保存義務を下回ってはならない）。
4. 帳簿及び証憑の保管場所・閲覧権限は代表取締役が定める。

## 第6条（月次締め）

1. 各月末日後 **[TBD] 営業日以内** に、当該月の仕訳を完了し、預金残高その他の主要科目を突合する（月次締め）。
2. 月次締めの結果は、経理担当者が取りまとめ、代表取締役又はその委任を受けた者が確認する。
3. 突合差異があるときは、原因を記録し、解消するまで翌月以降の締めを確定させない。少額で経営判断上許容する差異がある場合は、代表取締役の書面（電磁的記録を含む）による承認を要する。

## 第7条（決算）

1. 事業年度末日後 **[TBD] 日以内** に試算表を作成し、代表取締役が確認する。
2. 決算においては、少なくとも次の事項を確認する。
   1. 収益・費用の期間帰属
   2. 債権債務・棚卸資産・固定資産の実在性及び評価
   3. 役員報酬・交際費その他、税務上留意を要する科目の集計
   4. 前事業年度からの繰越及び資本（又は純資産）の整合
3. 税理士等へのレビュー又は顧問手続は、必要に応じて実施する。引き渡し資料の範囲は別紙1に従う。
4. 決算確定後、計算書類及び附属明細書その他法令・定款に定める書類を作成し、所定の機関（株主総会等）に提出する。
5. 電子申告・税務署等への提出手続そのものは、法人税務・申告準備規程その他の税務関連規程及び税理士等の手続による。本規程は社内の記帳・決算統制を定めるものであり、申告書の作成義務を税理士等に代わって履行するものではない。

## 第8条（資金・口座・支払）

1. 法人口座の残高把握、資金繰り、支払予定及び売掛・買掛の管理は、経理業務の一部として本条に従う。
2. 支払カレンダー（日付の確定した支払予定）を正本として維持し、給与・税・契約等から取り込むときは、取込後に人間が確認する。
3. 資金不足が見込まれるときは、不足日及び必要調達額を区別して記録し、代表取締役に報告する。
4. **振込の実行**は、稟議・決裁規程及び組織情報システム権限管理規程に従い、権限ある人間が行う。チャットその他に口座番号を出力してはならない。
5. 銀行明細の取込及び消込は、冪等・監査可能な手続による。消込済みデータの無断削除をしてはならない。

## 第9条（財務報告内部統制との関係）

1. 決算・財務報告プロセスの内部評価（いわゆる J-SOX の社内評価）を行う場合、評価の計画・実施・独立性は内部監査規程による。
2. 本規程は記帳・資金・決算の **運用統制** を定め、内部評価の手続そのものは内部監査規程に委ねる。評価結果をもって仕訳正本を黙って書き換えてはならない。

## 第10条（内部統制）

1. 経理担当者と承認者は分離する。少人数の会社においては、代表取締役が承認者を兼ねることができる。
2. 預金口座残高及び主要科目は、少なくとも月次で突合する。
3. 不正又は重大な誤謬を発見したときは、文書管理規程に従い記録し、代表取締役に報告する。
4. 仕訳正本の改ざん、事後の無断削除その他監査可能性を損なう行為をしてはならない。訂正が必要なときは、訂正仕訳又は会社が定める訂正手続による。

## 第11条（関連規程との関係）

本規程と他の社内規程が抵触するときは、法令に反しない範囲で、税務・会計の処理の統一を優先して解釈する。疑義があるときは代表取締役が決定する。

## 第12条（改定）

本規程の改定は、取締役会（又は株主総会）の決議による。
