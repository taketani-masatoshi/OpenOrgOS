## 議事の経過及びその要領

### 第1号議案　組織情報システム権限管理規程（REG-030）の制定

議長は、組織情報システム（OrgOS）における操作権限、承認手続、指示監査記録及び情報開示の取扱いを社内規程として明確にするため、次の規程を制定することを提案した。

| 項目 | 内容 |
|------|------|
| 規程ID | REG-030 |
| 規程名 | 組織情報システム権限管理規程 |
| 施行文 | [`docs/company/regulations/soshiki-joho-system-kengen-kisoku.md`](../regulations/soshiki-joho-system-kengen-kisoku.md) |
| 版 | v1.0 |
| 施行日 | **2026年7月15日** |

#### 決議事項

1. 上記 REG-030 を制定し、本日をもって施行する。
2. `tenants/mal/regulations.yaml` において REG-030 を有効とする。
3. 権限台帳等と本規程の対応表（`data/org/regulation-bindings.yaml`）を、本決議に基づき固定（凍結）する。実行時の照合は、当面「勧告（advisory）」とし、必要に応じ取締役会で強化する。

**結果:** 出席取締役全員の同意により、原案どおり可決した。
