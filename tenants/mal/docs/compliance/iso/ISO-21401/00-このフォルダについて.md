**標準テンプレート:** [steward/standards/iso/ISO-21401/](../../../../../../../steward/standards/iso/ISO-21401/00-このフォルダについて.md)  
**スコープ:** 亀沢旅館（PROP-002）· 開業 2026-09-18  
**位置づけ:** 当社が認証対象として運用する **唯一の ISO**（`standards.yaml`）

---

## 現状

`orgos --tenant mal iso audit run --dry-run` 時点で **24統制中 適合7・不適合17**。

不適合が多いのは、規格の主題である環境・社会文化・経済の運用がまだ始まっていないためで、
亀沢旅館が未開業であることの反映である。**開業後に実績を積む前提の状態**として正しい。

力量・教育訓練（7.2）のみ先行して整備済み。

## 開業前に優先すべきもの

法定・安全に直結するもの。

1. **力量・研修**（整備済 · 開業前研修が [計画](competence/研修計画-fy2026.md)どおり完了すること）
2. `guest-protection-policy.md` — 2023年改正旅館業法の宿泊拒否の判断基準。「なんとなく断る」を防ぐ
3. `risk-opportunities.csv` — 火災・停電・ゲスト負傷を含む初期のリスク特定
4. `kpi-log.csv` — 開業初月から記入を始める（後から遡れない）
