# TRN-003 消防設備の操作と避難誘導 実地訓練

**対象力量:** CMP-02（法定）　**形式:** 実地訓練 120分　**受講者:** 段燕燕 · 三塚力 · 鈴木友也  
**実施場所:** 亀沢旅館（PROP-002・東京都墨田区亀沢1）  
**ISO 21401:2018:** 8.1（運用の計画）· REG-012 第4条2 / 第9条 · REG-013

> 座学ではなく現地で実施する。図面上で理解していても、暗い中で階段を降りられるかは別の能力である。

---

## 学習目標

1. 消火器・自動火災報知設備の位置を、指示なしで示せる。
2. 2階客室からの避難誘導を、所要5分以内で実演できる。
3. 119番通報で伝えるべき事項を、原稿なしで言える。

---

## 事前準備（実施責任者）

- [ ] 建物図面（避難経路を朱書き）を人数分用意
- [ ] 消火器の設置位置・製造年・点検期限を一覧化
- [ ] 非常連絡先一覧（消防・警察・救急・設備業者・オーナー）を掲示位置に貼付
- [ ] 訓練用の想定を1つ選ぶ（下記シナリオ）
- [ ] **§確認事項 C**（[TRN-002](TRN-002-旅館業法と関係法令.md)）の回答を反映しておく

## 1. 設備の現地確認（30分）

全員で建物を回り、**各自が指をさして位置を言う**。口頭説明を聞くだけにしない。

| 確認対象 | 確認する内容 |
|---|---|
| 消火器 | 設置位置 · 圧力計の針が緑の範囲か · 期限 |
| 自動火災報知設備 受信機 | 位置 · 表示の読み方 · 音響停止と復旧の違い |
| 誘導灯・非常照明 | 点灯しているか · 前に物がないか |
| 避難経路（主・副） | 2経路あるか · 施錠されていないか · 障害物がないか |
| ブレーカー · ガス元栓 | 位置 · 遮断方法 |
| 非常連絡先の掲示 | ゲストから見える位置にあるか（REG-012 第4条2） |

**その場で是正する。** 廊下に物が置いてあれば訓練中に片付ける。「後で」は残らない。

## 2. 消火器の操作（20分）

訓練用水消火器があれば実際に放射する。なければ手順の口頭復唱と姿勢の確認まで行う。

1. **安全ピンを抜く**
2. **ホースを外し、火元に向ける**（炎の先ではなく燃えているものの根元）
3. **レバーを強く握る**
4. 立ったままではなく **姿勢を低く**、退路を背にして構える

**消火を試みる限界を先に決めておく。** 炎が天井に達したら消火を中止し、避難と通報を優先する。これは判断の訓練であり、器具の訓練ではない。

## 3. 通報訓練（15分）

119番で聞かれることを、順番に言えるようにする。

- 火事か救急か
- 住所（**東京都墨田区亀沢1丁目 …** — 番地まで正確に）
- 建物の名称・特徴（亀沢旅館・木造/3室の宿泊施設）
- 何が燃えているか、逃げ遅れの有無
- 通報者の氏名・連絡先

**建物の正確な住所を暗唱できるようにする。** パニック時に調べる余裕はない。

## 4. 避難誘導の実演（40分）

### シナリオ

> 平日 23:00。2階客室に宿泊者2名（うち1名は日本語を解さない外国人）。1階厨房付近から出火し、自動火災報知設備が鳴動した。

### 実演手順

1. 受信機で発報場所を確認する
2. 出火場所の確認に向かう（1名）· 通報する（1名）
3. **2階客室のドアを叩き、宿泊者に声をかける** — 呼びかけ文は日英で用意する
4. 誘導灯に沿って主経路で1階外へ誘導する
5. 集合場所（建物から離れた安全な位置）で **人数を確認する**
6. 消防隊到着時に、逃げ遅れの有無と出火場所を伝える

### 多言語対応

外国人宿泊者への呼びかけは、通じることが目的で、正しい文法は目的ではない。短く、繰り返す。

- "Fire! Please evacuate now. Follow me."
- "火事です。すぐに外へ出てください。"

三塚力（翻訳・通訳）が中心となり、**中国語を含む3言語の掲示文** を作成して客室に備える。掲示は訓練の成果物とする。

### 計測

集合場所での人数確認完了までを計測する。**5分以内** を合格基準とする。超えた場合は原因（経路の障害物・呼びかけの手間取り・鍵）を特定し、その場で再実施する。

## 有効性の確認

| 判定 | 基準 |
|---|---|
| 有効 | 設備位置を指示なしで示せた **かつ** 誘導を5分以内で完了した |
| 一部 | いずれか一方のみ |
| 不十分 | 両方できない |

「一部」「不十分」は日を改めて再実施する。開業日 **2026-09-18** までに全員が「有効」になっていること。
