# TRN-002 旅館業法・消防法・墨田区条例の要求事項

**対象力量:** CMP-01（法定）　**形式:** 集合研修 90分　**受講者:** 段燕燕 · 宮城万貴子 · 三塚力 · 鈴木友也  
**ISO 21401:2018:** 4.2（利害関係者のニーズ）· 7.2（力量）· REG-012 第4条1

> **重要:** 本教材は社内教育用の整理であり、法令の正文ではない。
> 個別の判断は、必ず **所轄保健所（墨田区）· 所轄消防署（本所消防署）· 墨田区の担当課** に確認する。

## 学習目標

1. 亀沢旅館がどの営業種別の許可で営業しているかを言える。
2. 変更届が必要になる場面を3つ挙げられる。
3. 行政の立入検査を受けたとき、何を提示するかを言える。

## 1. 旅館業法の全体像（25分）

旅館業は **都道府県知事等（保健所を設置する市では市長）の許可** を受けて営む。無許可営業は罰則の対象。

営業種別（2018年改正後）:

| 種別 | 概要 |
|---|---|
| 旅館・ホテル営業 | 改正前の「ホテル営業」と「旅館営業」が統合された種別 |
| 簡易宿所営業 | 客室を多数人で共用する構造・設備を主とするもの |
| 下宿営業 | 1か月以上の期間を単位として宿泊させるもの |

住宅宿泊事業法（民泊）や特区民泊は **別の制度** で、営業日数の上限や届出先が異なる。どの制度で営業しているかによって、義務も記録も変わる。

**§確認事項 A:** 亀沢旅館（PROP-002）の許可種別と許可番号・許可年月日を確認し、本書と `data/properties/PROP-002.yaml` に反映する。1棟貸し・3室という形態から種別が決まっているはずである。

### 主な義務

- **宿泊者名簿の備付け**（旅館業法第6条）→ 詳細は [TRN-004](TRN-004-宿泊者名簿と個人情報.md)
- **構造設備基準の維持** — 許可時の図面どおりの状態を保つ
- **衛生措置** — 換気・採光・照明・防湿・清潔
- **宿泊拒否の制限** — 法定の事由がなければ宿泊を拒めない。2023年改正で、感染症を理由とする不当な拒否や、障害を理由とする差別的取扱いをしてはならないことが明確化された

**§確認事項 B:** 宿泊拒否できる法定事由の最新の条文と、墨田区の運用を確認する。「なんとなく断る」は違法になり得るため、判断基準を文書化する。

## 2. 消防法（25分）

宿泊施設は不特定多数が利用するため、消防法上の扱いが住宅より厳しい。

論点は3つ。

1. **消防用設備等の設置** — 消火器・自動火災報知設備・誘導灯など。何が必要かは用途と規模で決まる
2. **点検と報告** — 有資格者による定期点検と、消防長等への報告
3. **防火管理者の選任** — 一定の収容人員を超える防火対象物で必要。選任したら消防計画を作成し届け出る

**§確認事項 C:** 亀沢旅館の収容人員と、それに基づく (a) 防火管理者選任の要否 (b) 必要な消防用設備 (c) 点検・報告の頻度 を本所消防署に確認する。3室の小規模施設でも、用途が宿泊であることで住宅とは基準が変わる。

現場で全員が知っているべきこと（規模に関わらず）:

- 消火器の位置
- 自動火災報知設備の受信機の位置と、鳴動時の初動
- 避難経路と、それを塞がないこと（廊下・階段に物を置かない）

→ 実地は [TRN-003](TRN-003-消防避難訓練.md) で扱う。

## 3. 自治体の条例・要綱（20分）

墨田区・東京都のレベルで、法律に上乗せ・横出しの要求がある場合がある。典型的には次の領域。

- 宿泊施設の設置に関する近隣説明・標識の掲示
- 廃棄物の排出方法（事業系ごみは家庭ごみと扱いが異なる）
- 生活環境（騒音・振動・悪臭）に関する規制
- 宿泊税（東京都）の特別徴収義務の有無

**§確認事項 D:** 上記4点について、墨田区・東京都の該当条例と亀沢旅館への適用有無を確認する。**事業系ごみの扱い** は開業初日から発生するため優先度が高い。

**§確認事項 E:** 東京都宿泊税の課税対象（宿泊料金の水準による）に亀沢旅館が該当するかを確認する。該当する場合、特別徴収・申告の実務を管理部門の業務に組み込む。ADR 2,000円/泊という現行計画（`data/properties/PROP-002.yaml`）との関係で判断が変わる。

## 4. 変更があったとき（10分）

許可の前提が変わったら届出が要る。開業後に起きやすいもの:

| 場面 | 想定される手続 |
|---|---|
| 代表者・法人の名称や所在地の変更 | 変更届 |
| 施設の構造設備の変更（客室数・間取り・用途） | 事前相談 → 変更許可または変更届 |
| 営業の休止・廃止 | 届出 |
| 防火管理者の変更 | 消防署への届出 |

**判断に迷ったら、変更してから相談ではなく、変更する前に相談する。** 構造設備の変更は、事後だと是正費用が大きい。

## 確認テスト（10問・8問以上で「有効」）

1. 亀沢旅館の営業種別と許可番号は何か。
2. 無許可で旅館業を営むとどうなるか。
3. 宿泊者名簿の備付けを義務づけているのは何法の何条か。
4. 2023年の旅館業法改正で明確化された、宿泊拒否に関する考え方は何か。
5. 消防用設備の点検は誰が行い、どこへ報告するか。
6. 自動火災報知設備が鳴ったとき、最初に何をするか。
7. 避難経路について、日常業務で守るべきことは何か。
8. 事業系ごみは家庭ごみと何が違うか。
9. 客室の間取りを変更したいとき、いつ誰に相談するか。
10. 行政の立入検査で提示を求められる可能性が高い記録を3つ挙げよ。
