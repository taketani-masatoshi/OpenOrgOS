# TRN-005 清掃基準の理解と委託先作業の検収（OJT）

**対象力量:** CMP-03　**形式:** OJT 150分　**受講者:** 三塚力 · 鈴木友也  
**実施場所:** 亀沢旅館（PROP-002）　**ISO 21401:2018:** 8.1（運用）· 8.4 相当（外部提供者の管理）  
**根拠:** REG-012 第4条3 · 第8条 · CTR-012（清掃委託契約）

---

## 学習目標

1. CTR-012 の清掃基準を、チェックリストの各項目の意図まで含めて説明できる。
2. 1棟の検収を単独で実施し、代表取締役の再点検との差異を2項目以内に収める。
3. 不適合を見つけたとき、委託先への伝え方と記録の残し方を実行できる。

---

## 1. 委託しても責任は残る（20分）

清掃を CTR-012 で外部委託していても、**衛生水準に対する責任は営業者（当社）にある**。旅館業法の衛生措置の名宛人は営業者であり、「委託先がやらなかった」は抗弁にならない。

ISO 21401 の観点でも、外部に委託したプロセスは管理の対象から外れるのではなく、**管理方法を決めて監視する対象** になる。だから検収がある。

検収の目的は3つ。

1. 契約した水準が満たされているかの確認
2. 満たされていないときの是正
3. **繰り返し発生する不備の把握**（3回目の同じ指摘は、清掃員の問題ではなく基準か手順の問題）

## 2. 清掃基準の読み合わせ（30分）

CTR-012 のチェックリストを1項目ずつ読み、**なぜその項目があるか** を確認する。項目の意図を知らないと、形式的に丸をつけるだけになる。

領域ごとの着眼点:

| 領域 | 見るところ | 見落としやすい点 |
|---|---|---|
| 水回り（浴室・洗面・トイレ） | 排水口 · 目地のカビ · 鏡の水垢 | **排水口の内側**、便座の裏、シャワーヘッド |
| 寝具 | シーツ・枕カバーの交換 · 髪の毛 | マットレスパッド、ベッド下 |
| 客室 | 床 · 什器の埃 · ゴミ箱 | 家具の下、エアコンのフィルター、リモコン等の高頻度接触面 |
| 厨房・共用部 | 油汚れ · 排水 · 冷蔵庫内 | 換気扇、生ゴミの残置 |
| アメニティ・消耗品 | 補充数 · 有効期限 | 環境配慮型の指定品が使われているか（REG-012 第6条2） |
| 全体 | 臭い · 前泊者の痕跡 | **忘れ物**（発見時の取扱いを決めておく） |

**環境の観点を検収に入れる。** 第6条2は環境配慮型の洗剤・消耗品を求めている。指定外の製品が使われていたら、清掃品質は合格でも **方針上は不適合** である。この二重の視点が ISO 21401 の特徴。

## 3. 検収の実演（60分）

### 手順

1. チェックリストを持ち、**決めた順路** で回る（順路を固定しないと見落とす）
2. 各項目で合否を記入する。「だいたいきれい」で丸をつけない
3. 不備は **写真を撮る**。口頭指摘は伝わらないし残らない
4. 忘れ物・破損・設備不良は清掃の不備と分けて記録する
5. 所要時間を記録する

### 判定基準

受講者が単独で検収した結果と、代表取締役が同じ棟を再点検した結果を突き合わせる。**差異2項目以内** で「有効」。

差異が出た項目は、その場で現物を見ながら「なぜ自分は合格と判断したか」を言語化する。基準の解釈のずれが原因なら、チェックリストの表現を直す（成果物として持ち帰る）。

## 4. 不適合への対応（30分）

| 段階 | 対応 | 記録 |
|---|---|---|
| 軽微・単発 | その場で手直し、または当社で対応 | 検収記録に残す |
| 重大（衛生・安全に影響） | ゲスト受入れを止める判断を含む。経営へ即時報告 | 検収記録 + 是正処置 |
| 繰り返し | 委託先と基準の認識合わせ。契約条件の見直しを検討 | 是正処置（REG-016） |

**伝え方。** 委託先は取引先であり、指摘は関係を壊す作業ではない。写真と基準の該当項目を示し、事実として伝える。人ではなく作業について話す。REG-012 第8条は委託先の監督を求めるが、これは監視ではなく **合意した水準を維持するための仕組み** である。

### 記録の保存

清掃・メンテ記録は **3年保存**（REG-012 第10条1）。確定後の追記修正はせず、新規行で残す（REG-007）。

---

## 有効性の確認

単独検収を実施し、再点検との差異が2項目以内であれば「有効」。3項目以上なら、原因を特定したうえで次回チェックアウト時に再実施する。
