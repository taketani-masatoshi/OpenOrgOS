# TRN-004 宿泊者名簿の作成・保存と個人情報保護

**対象力量:** CMP-04（法定）　**形式:** 集合研修 60分　**受講者:** 三塚力 · 鈴木友也  
**ISO 21401:2018:** 7.5（文書化した情報）· REG-012 第10条2 · REG-010

> **重要:** 本教材は社内教育用の整理である。記載事項・保存年限・外国人宿泊者の取扱いは
> **所轄保健所（墨田区）** に確認し、確認結果で本書と
> [宿泊者名簿運用規則](../../../../../properties/PROP-002-kamezawa/operations/guest-register-rules.md) を更新する。

## 学習目標

1. 宿泊者名簿の記載必須項目を、漏れなく挙げられる。
2. 外国人宿泊者の場合に追加で必要となる取扱いを説明できる。
3. 名簿を「個人情報」として、誰がいつ見てよいかを言える。

---

## 1. なぜ名簿が法定なのか（10分）

宿泊者名簿は、旅館業法第6条により **営業者に備付けが義務づけられた記録** である。ゲスト管理の利便のための台帳ではなく、感染症の発生時や事件・事故の際に、行政・警察が宿泊者を追跡できるようにするための公的な記録という位置づけを持つ。

このため、次の3点が通常の顧客名簿と異なる。

1. **記載しないことが違法になり得る**（任意の営業判断ではない）
2. **保存期間が法で定まっている**
3. **行政の立入検査で提示を求められる**

同時に、名簿は個人情報保護法上の個人情報でもある。**法定で集めるが、目的外に使ってはならない**という二重の性格を持つ。

## 2. 記載事項（20分）

旅館業法および同法施行規則に基づき、少なくとも次を記載する。

| 項目 | 補足 |
|---|---|
| 氏名 | 代表者だけでなく宿泊者全員 |
| 住所 | |
| 職業 | |
| 宿泊日 | |
| その他厚生労働省令で定める事項 | 連絡先など |

**日本国内に住所を有しない外国人** については、さらに次が必要とされる。

| 項目 | 補足 |
|---|---|
| 国籍 | |
| 旅券番号 | |
| 旅券の写し | 提示を求め、写しを保存する |

**§確認事項 F:** 上記の各項目、および **旅券の写しの保存方法・保存期間** を保健所に確認する。特に電子的な保存を認めるかは運用に幅があるため、亀沢旅館での具体的な方法（紙で保管するのか、スキャンして保管するのか）を確定させる。

**§確認事項 G:** 名簿の保存期間を確認する（施行規則上は3年とされる）。REG-012 第10条1 は清掃・メンテ・クレーム記録を3年としているが、**名簿は別の根拠で保存期間が決まる** ため、混同しない。

### よくある不備

- 代表者1名しか書かず、同行者を記載していない
- 「職業」欄の空欄
- 外国人宿泊者に旅券の提示を求めていない
- 事前オンライン予約の情報だけで済ませ、チェックイン時の名簿記帳を省略している

## 3. 模擬記帳（20分・演習）

次の3ケースについて、実際の様式に記入する。

**ケース1** — 国内在住の日本人2名（夫婦）が1泊。
**ケース2** — 米国在住の外国人3名（うち1名は乳児）が2泊。OTA 経由の予約。
**ケース3** — 日本国内に住所のある外国籍の方1名が1泊。

**ケース3の論点:** 「外国人」ではなく **「日本国内に住所を有しない者」** が旅券関連の追加項目の対象である。国内在住であれば、日本人と同じ取扱いになる。国籍で機械的に判断しないこと。これは差別的取扱いの防止（2023年改正の趣旨）とも関わる。

**判定:** 3ケースを誤りなく完了できれば「有効」。

## 4. 個人情報としての取扱い（10分）

REG-010（個人情報保護規程）に従う。名簿に固有の注意点。

| 論点 | 取扱い |
|---|---|
| 保管場所 | 施錠可能な場所、または権限を絞った電子的保管。`docs/properties/PROP-002-kamezawa/operations/` 配下で管理し、**Git には追跡させない** |
| 閲覧できる者 | 業務上必要な者に限る。清掃委託先には見せない |
| 目的外利用 | 販促メールへの流用は目的外。利用目的の通知の範囲を超えない |
| 第三者提供 | 原則不可。行政・警察からの請求は根拠を確認し、経営に報告してから対応する |
| 廃棄 | 保存期間経過後は復元できない方法で廃棄し、廃棄した事実を記録する |

**AI・チャットへの入力を禁じる。** 宿泊者名簿は L2 相当のデータであり、要約であっても本文を Git 追跡ファイルやチャットに転記しない（データ分類ルール）。

## 確認テスト

1. 宿泊者名簿の備付けを義務づけている法令・条文は何か。
2. 記載必須項目を5つ挙げよ。
3. 旅券の写しが必要になるのはどういう人か。「外国人」との違いを説明せよ。
4. 名簿の保存期間は何年か。その根拠は何か。
5. 清掃委託先が「部屋の名前を確認したい」と言ってきた。どう対応するか。
6. 保存期間を過ぎた名簿はどうするか。
