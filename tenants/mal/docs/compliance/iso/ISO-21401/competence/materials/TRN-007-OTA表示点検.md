# TRN-007 OTA・自社サイト表示の点検（OJT）

**対象力量:** CMP-07　**形式:** OJT 60分　**受講者:** 三塚力 · 鈴木友也  
**ISO 21401:2018:** 8.1（運用）· 7.5（文書化した情報の管理）  
**根拠:** REG-012 第4条4（表示と実態の一致）· CTR-010 / CTR-011（OTA 契約）

---

## 学習目標

1. 掲載内容と現況の差異を、決めた観点で洗い出せる。
2. 差異を修正し、修正した事実を記録として残せる。
3. 表示を変える必要が生じる場面を、業務の中で認識できる。

---

## 1. なぜ表示が管理対象なのか（10分）

掲載内容は広告であると同時に、**ゲストとの合意内容** である。実態と違えば、苦情の原因になるだけでなく、景品表示法上の問題や契約不履行の問題になり得る。REG-012 第4条4 が運営基準の一項目として表示を挙げているのはこのためである。

ISO 21401 の観点では、表示は「文書化した情報」の一種として **最新版が維持されているか** が問われる。1年前の写真が載り続けている状態は、文書管理の不備と同じ構造にある。

**サステナビリティ表示には特に注意する。** 「環境に配慮した宿」と掲げるなら、その裏づけ（REG-014 の月次記録、環境配慮型消耗品の実使用）が必要である。裏づけのない環境訴求は、規格が最も嫌う類の不適合になる。

## 2. 点検の観点（15分）

OTA2社（CTR-010 / CTR-011）と自社サイトについて、同じ観点で見る。

| 観点 | 確認内容 | 差異が起きやすい原因 |
|---|---|---|
| **販売単位・定員** | 1棟貸しか室単位か。最大宿泊人数 | 物理3室と販売単位1棟の混同 |
| **写真** | 現況と一致するか。家具・内装の変更後か | 改装・什器入替後の更新漏れ |
| **設備・アメニティ** | Wi-Fi · 空調 · キッチン · 洗濯機 · 駐車場 | 故障中の設備が「あり」のまま |
| **料金・課金** | 料金 · 清掃料 · 追加人数料金 · 税の表示 | 料金改定の反映漏れ |
| **チェックイン/アウト** | 時刻 · 無人チェックインの手順 | 運用変更の反映漏れ |
| **ハウスルール** | 騒音 · ゴミ出し · 喫煙 · 近隣配慮 | REG-012 第7条の内容が載っていない |
| **立地情報** | 最寄駅からの経路 · 周辺工事 | 一時的事情の未反映 |
| **環境の取組み** | 掲げた内容に裏づけがあるか | 実態を伴わない訴求 |
| **キャンセル規定** | OTA 側規定と自社規定の整合 | 2社間で条件が食い違う |

**2社間の整合も見る。** OTA-A と OTA-B で条件が違うと、ゲストは有利な方を主張する。

## 3. 実施（25分）

1. 上記観点の一覧を印刷またはシート化する
2. **現地で** 掲載画面を開き、実物と突き合わせる（机上でやらない）
3. 差異を記録する — 媒体 · 項目 · 掲載内容 · 実態 · 対応
4. **その場で修正できるものは修正する**
5. 修正できないもの（料金体系の変更など）は経営に上げる

## 4. 記録と定例化（10分）

点検結果は日付入りで残す。「いつ時点で一致を確認したか」が、後から表示の妥当性を説明する根拠になる。

**定例化。** 開業後は次のタイミングで点検する。

| 契機 | 対象 |
|---|---|
| 月次 | 全観点（軽い確認） |
| 設備の故障・復旧時 | 該当設備の表示 |
| 料金改定時 | 料金・税の表示（全媒体） |
| 改装・什器入替時 | 写真・設備 |
| 表示に関する苦情の発生時 | 該当項目 + 全媒体の横展開 |

**苦情との接続。** [TRN-006](TRN-006-ゲスト対応とクレーム.md) ケース3のような「表示と違う」という苦情が出たら、その1件を直して終わりにせず、**全媒体の同種項目を点検する**。

---

## 有効性の確認

OTA2社の掲載内容と現況の差異を洗い出し、修正まで完了できれば「有効」。差異ゼロだった場合は、点検の観点をすべて実施した記録があることをもって「有効」とする。
