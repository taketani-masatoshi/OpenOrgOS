# 力量・教育訓練（ISO 21401:2018 7.2）

**株式会社MAL**　**対象:** 亀沢旅館（PROP-002）　**開業日:** 2026-09-18  
**統制:** `CTL-CORE-competence`（ISO-21401 7.2）

ISO 21401 7.2 は、(a) 必要な力量の決定 (b) 力量の充足の確認 (c) 不足への措置 (d) 措置の有効性の評価 を求める。本フォルダはその4つに対応する記録を持つ。

---

## 構成

| 文書 | 7.2 の対応 | 生成元 |
|---|---|---|
| [力量マップ](力量マップ.md) | (a) 必要な力量 · (b) 充足の確認 | `data/hr/competence.yaml` |
| [研修計画 FY2026](研修計画-fy2026.md) | (c) 不足への措置 | `data/hr/training.yaml` |
| [研修実施記録](研修実施記録.md) | (d) 有効性の評価 | `data/hr/training.yaml` |
| [materials/](materials/) | 教材 | 手書き（正本） |

**3つの表は生成物であり、直接編集しない。** 正本は `data/hr/` の2つの YAML で、次のコマンドで再生成する。

```bash
orgos --tenant mal hr competence map --write
orgos --tenant mal hr competence plan --write
orgos --tenant mal hr competence records --write
```

整合の検査:

```bash
orgos --tenant mal hr competence check
```

法定要求の力量ギャップが研修計画で手当てされていない場合、または力量マップが実在しない従業員・力量を参照している場合に異常終了する。

---

## 運用

| 契機 | 作業 |
|---|---|
| 研修を実施した | `training.yaml` の `records` に結果を追記 → `records --write` |
| 力量を再評価した | `competence.yaml` の `assessments` を更新 → `map --write` |
| 入社・異動 | `competence.yaml` の `roles.members` を更新 → `check` で漏れを確認 |
| 年1回（マネジメントレビュー前） | 全員の力量を再評価し、次年度の研修計画を作る |

**記録は上書きしない。** 実施記録は REG-007 に従い、確定後は新規行として追加する。
