# 個人情報取扱い・同意・宣言ルール（社内）

**株式会社MAL**  
**文書ID:** OPS-PRIV-001  
**版:** v1.0  
**制定:** 2026年6月6日（REG-010 運用細則）  
**関連:** [REG-010](../../company/regulations/kojin-joho-hogo-kisoku.md)

---

## 1. 目的

個人情報保護規程を **現場で実行** するため、取得時の同意、宣言、記録、削除のルールを定める。

## 2. 適用

宿泊（亀沢）、OTA、翻訳・SES、採用（将来）、委託先管理。

## 3. 取得時のルール

| 場面 | 必須措置 | 記録 |
|------|---------|------|
| **亀沢チェックイン** | [宿泊者向け告知](guest-privacy-notice.md) を掲示・説明 | [宿泊者名簿](../lodging/templates/compliance/宿泊者名簿.csv) |
| **外国籍宿泊** | 旅券確認、届出準備 | 名簿 + [外国人宿泊者届](../lodging/templates/compliance/外国人宿泊者届.csv) |
| **OTA 予約** | プラットフォーム規約が同意の根拠。必要項目は **自社名簿へ転記** | 名簿 |
| **翻訳・SES 受注** | 契約又はメールで利用目的を明示。原稿の個人名は **最小利用** | 案件フォルダ（Git 非推奨） |
| **採用（将来）** | 履歴書提出時に [利用目的の書面](templates/採用時個人情報同意書.md) | hr/records/ |
| **委託先担当者** | 契約の秘密保持条項 | 契約台帳 |

## 4. 同意の原則

1. **明示:** 利用目的を分かる言葉で示す（告知文・契約・口頭+記録）。
2. **最小取得:** 宿泊に不要な要配慮個人情報は取得しない。
3. **OTA:** 当社が追加で連絡する場合、メッセージ内で目的を再確認する。
4. **オプトアウト:** マーケティング目的の利用は **行わない**（現時点）。

## 5. 宣言（社内）

代表取締役及び個人データに触れる者は、次を遵守することを **自己宣言** する（入社・規程制定時。新規雇用時も同様）。

1. REG-009・REG-010 を読み、理解した
2. 個人データを **業務目的外** に使用しない
3. 端末の **画面ロック・MFA** を設定する
4. 漏えいの疑いがある場合 **24時間以内** に代表取締役へ報告する
5. `records/` のデータを **無断で外部に持ち出さない**

**宣言記録:** [templates/個人情報取扱宣言.csv](templates/個人情報取扱宣言.csv) → `records/`

## 6. パスポート・旅券情報

| ルール | 内容 |
|--------|------|
| 保管 | 届出に必要な期間のみ。画像は **暗号化ストレージ**（Git 禁止） |
| アクセス | 代表取締役2名のみ |
| 削除 | 届出完了後 **1年以内** に削除（延長する場合は理由を記録） |
| 複写 | ゲストへの **不要なコピー保管** をしない |

## 7. 委託先・OTA

| 委託先 | 確認事項 |
|--------|---------|
| OTA（CTR-010/011） | プライバシーポリシー、データ保存国、ダウンロード権限 |
| 清掃（CTR-012） | ゲスト情報を **渡さない**（入室日時・鍵のみ） |
| 竹谷（CTR-001） | 経営データのみ。ゲスト個情は対象外 |

## 8. 漏えい時

1. 発見 → 24h 以内に REG-009 インシデント開始  
2. REG-010 第8条に従い PPC 報告・本人通知を検討  
3. [templates/個人情報インシデント記録.csv](templates/個人情報インシデント記録.csv) に記録 → `records/`

## 9. 定期見直し

**年1回**（内部監査時）、本ルールと告知文を見直す。
