# 苦情・有害事象等の収集手順（GVP）

**文書番号:** GVP-002  
**会社:** 株式会社MAL  
**制定:** 2026-09-06

---

## 1. 目的

株式会社MAL が市販後に得る安全情報を、漏れなく · 遅滞なく受け付け、評価へ渡す。

## 2. 収集源

- 使用者 · 医療従事者 · 施設
- 販売店 · 代理店 · 輸入元
- 文献 · 学会 · 規制当局 · 海外当局
- 社内（製造不適合、出荷後発見）

## 3. 受付

1. GVP-FRM-001 で受付日 · 情報源区分 · 品目 id · ロット（分かる範囲）· 事象の L1 要約を記録する。
2. 同一日に苦情台帳又は有害事象台帳へ登録する。
3. 患者氏名 · 住所 · 電話は様式の社内控えにも書かない。調査に必要な場合は施設 id に留める。

## 4. 初動（24 時間以内）

1. 死亡 · 重篤 · 集団発生のおそれは、受領当日中に安全管理責任者へ口頭又は社内経路で上げる。
2. 欠落情報（ロット、使用状況）は追加照会するが、当局提出は人間が行う。
3. 製品との関連が不明でも、安全情報として受け付ける。

## 5. 台帳

- 苦情: `ledgers/complaint-records.yaml`
- 有害事象: `ledgers/adverse-event-records.yaml`

CLI: `orgos operations medical-device complaint add` / `ae add`。
