## 1. 目的 · 適用範囲

株式会社MAL が （医療機器名称） を製造 · 組立するときの標準手順を定める。委託製造の場合は、本 SOP を委託先管理の基準とし、委託先固有手順との差分を購買記録に残す。

## 2. 責任

| 役割 | 責任 |
|------|------|
| 製造管理者 | 作業許可、逸脱判定、ロット合否 |
| 作業責任者 | 本 SOP どおりの実施と記録 |
| 品質担当 | 工程内 · 完成品検査 |

## 3. 使用資材 · 機器

作業前に次を確認し、ロット記録（QMS-FRM-001）へ転記する。

| 項目 | 確認 |
|------|------|
| 資材の品目 id · 受入状態 | 承認供給者かつ受入合格 |
| 資材ロット · 使用期限 | 期限内 |
| 設備 · 治工具 | 校正又は日常点検済み |
| 作業環境 | 定められた清浄度 · 温湿度 |

空欄のまま製造を開始しない。

## 4. 作業手順

1. **作業前確認** — 図面 · SOP の版、清浄度、校正済機器、保護具。
2. **払出** — 所要数量のみ払い出し、残りは識別して保管する。
3. **組立 / 製造** — 承認された順序で実施する。工程逸脱は直ちに作業を止め、製造管理者へ報告する。
4. **工程内検査** — 定められた特性を測定し、記録する。
5. **完成品検査** — 出荷判定基準に対する合否。
6. **ラベリング · UDI** — 承認された表示のみを用いる。手書きの改変は禁止。
7. **包装 · 保管** — 保管条件に従い、出荷待ちとして識別する。

## 5. 不適合

不合格ロットは隔離し、QMS-SOP-003 及び CAPA 規程に従う。廃棄 · 特別採用は製造管理者が記録する。

## 6. 記録

製造ロット記録（QMS-FRM-001）及び `ledgers/manufacturing-batch-records.yaml`。トレーサビリティに必要な範囲で品目 id とロットを残し、個人情報は書かない。
