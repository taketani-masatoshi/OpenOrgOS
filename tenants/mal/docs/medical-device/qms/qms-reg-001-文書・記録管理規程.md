# 文書・記録管理規程（第2階層）

**文書番号:** QMS-REG-001  
**版:** 1.0  
**制定:** 2026-09-06  
**会社名:** 株式会社MAL

---

## 第1条（目的）

株式会社MAL の QMS 文書及び記録の作成 · 照査 · 承認 · 配布 · 改訂 · 保管 · 廃棄を統制し、誤った版の使用を防ぐ。

## 第2条（適用範囲）

品質マニュアル · 規程 · SOP · 様式 · 記録、GVP 文書、及び外部文書の管理に適用する。運用台帳 YAML も記録として扱う。

## 第3条（文書番号体系）

| 接頭辞 | 意味 |
|--------|------|
| QMS-MAN | 品質マニュアル |
| QMS-REG | 規程 |
| QMS-SOP | 手順書 |
| QMS-FRM | 様式 |
| GVP | 安全管理手順 |
| GVP-FRM | 安全管理様式 |

改訂は版番号を 1 ずつ上げる。ファイル名は `orgos operations medical-device qms draft` が付与する規則に従う。

## 第4条（作成 · 照査 · 承認）

1. 作成者はカタログのテンプレートから下書きする。
2. 照査者は規制要求と他文書との矛盾を確認する。
3. 承認者は人間とし、稟議主題は `medical_device.doc_revision` とする。
4. 承認前の文書は文書管理台帳で `draft` 又は `in_review` とする。

## 第5条（改訂 · 廃止）

1. 改訂時は変更理由を文書管理台帳に残し、旧版を `obsolete` にする。
2. 廃止した文書は誤用されないよう識別する。
3. 配布先（製造 · 販売 · 安全管理）へ改訂を周知する。

## 第6条（記録の保管）

製造 · 出荷 · 苦情 · 有害事象 · 教育 · CAPA 等の記録は **5 年間**（法規でより長い場合は従う）保管する。個人の住所 · 口座は記録に書かず、必要な場合は識別子リンクのみとする。

## 第7条（文書管理台帳）

正本は `data/medical-device/ledgers/document-control-records.yaml`。CLI: `orgos operations medical-device ledger`。
