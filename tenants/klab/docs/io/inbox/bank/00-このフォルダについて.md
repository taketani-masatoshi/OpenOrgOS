# 銀行明細（CSV）

投入先: `docs/io/inbox/bank/`

## 受入形式

- **CSV / TSV**（UTF-8 推奨）
- PDF はこのフォルダに置いても **parse しません**。銀行サイトの CSV ダウンロード、または `pdftotext` 等で CSV/MD に変換してから投入してください。

## 正規列（推奨）

```
date,direction,amount,category,description,account_id,reference,counterparty
2025-01-15,outflow,3300,通信費,NTTドコモ,BANK-001,,
```

## 取込手順

```bash
orgos ingest scan --write
orgos ingest parse --source bank --write
orgos ingest classify --write
orgos ingest review
orgos ingest post --batch <batch_id> --write
```
