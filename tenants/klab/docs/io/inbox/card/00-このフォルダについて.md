# クレジット明細（CSV）

投入先: `docs/io/inbox/card/`

- **CSV**（各カード会社の明細ダウンロード）
- PDF は外部で CSV/MD 化してから投入

```
date,amount,description,payee,category
2025-01-20,2180,スターバックス渋谷,スターバックス,接待交際費
```

```bash
orgos ingest scan --write
orgos ingest parse --source card --write
orgos ingest classify --write
orgos ingest post --batch <batch_id> --write
```
