# マーケットプレイス明細（Amazon 等）

投入先: `docs/io/inbox/marketplace/`

```
date,amount,description,payee,order_id
2025-03-05,4580,USBハブ,Amazon.co.jp,123-4567890-1234567
```

10万円超は仕訳せず expense-intake へ誘導されます。

```bash
orgos ingest scan --write
orgos ingest parse --source marketplace --write
orgos ingest classify --write
orgos ingest post --batch <batch_id> --write
```
