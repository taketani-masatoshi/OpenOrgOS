## 所見

- 複式（正規の簿記）· 貸借対照表· 損益計算書 → 最高55万円（国税庁 No.2072）
- e-Tax / 優良電帳の証跡なし → 55万円まで（OrgOS は e-Tax を送信しない）
- 適用額は事業所得 256,193 円を上限

令和9年分以後は制度改正で最大75万円等の区分がある。本ゲートは令和8年分までの55/65を対象とする。
