# docs/contracts/

契約**本文**（人が読む MD）。台帳は `data/contracts/CTR-*.yaml`。

## 組織間契約

相手組織との契約は **起票側テナントのみ** に `01-draft.md` を置く（P0〜P2）。  
相手側は `docs/io/inbox/` に受領版を归档。稟議（P3）以降に双方が台帳登録。

正本: [steward/rules/inter-org-contract-workflow.md](../../../../steward/rules/inter-org-contract-workflow.md)

## 社内契約

単一テナント内の契約は従来どおり `docs/contracts/CTR-*/` に draft / executed を置く。
