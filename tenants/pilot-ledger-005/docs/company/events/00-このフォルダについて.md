# 会社イベント記録 — events/

**正本:** [steward/rules/company-events-layout.md](../../../../steward/rules/company-events-layout.md)

## 役割

**経緯・決議・タイムライン** を月次（`YYYY-MM`）で保管します。登記ドラフト等の **書類本文** は `../artifacts/` に分離します。

## 構成

```
events/
├── 00-このフォルダについて.md
└── {YYYY-MM}/
    ├── _INDEX.md                              # 当月一覧（CLI 自動更新）
    └── EVT-{YYYYMMDD}-{kind}-{slug}.md        # イベント記録
```

## CLI

```bash
npm run orgos -- events ensure-month
npm run orgos -- events new --kind registration --title "設立登記準備"
npm run orgos -- events list --month 2026-06
```

**台帳:** `data/company-events.yaml`

## AI 参照

- イベント narrative → `@docs/company/events/{YYYY-MM}/EVT-*.md`
- 書類 → `@docs/company/artifacts/{YYYY-MM}/{event-id}/`
- Cursor ルール: `.cursor/rules/company-events.mdc`
