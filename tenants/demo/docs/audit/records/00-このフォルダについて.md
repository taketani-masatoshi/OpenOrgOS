# 記録監査（records_audit）

**Agent:** `records_audit` · **正本:** [records_audit_agent.md](../../../../steward/core/agents/records_audit_agent.md)

## 目的

会社イベント台帳（`EVT-*`）とハッシュチェーンの整合性監視。週次 Ed25519 バッチ署名と月次監査レポートを担当。

## 関連パス

| 種別 | パス |
|------|------|
| 台帳 | `data/company-events.yaml` |
| チェーン | `data/company-events-chain.jsonl` |
| 週次署名 | `data/company-events-attestations.jsonl` |
| イベント MD | `docs/company/events/` |
| Agent 要約 | `docs/reports/agent-summaries/records-audit/` |

## CLI

```bash
orgos events chain verify
orgos events chain attest
orgos events audit monthly
orgos events chain export --out ./audit-bundle
orgos events chain migrate
```
