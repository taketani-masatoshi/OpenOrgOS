# 領収書・証憑（MD / TXT / CSV）

投入先: `docs/io/inbox/receipts/`

```markdown
# 領収書

- date: 2025-01-12
- amount: 3300
- payee: NTTドコモ
- description: 携帯電話料金
- tax_inclusive: true
```

PDF は `pdftotext` 等で MD/TXT にしてから投入。

```bash
orgos ingest scan --write
orgos ingest parse --source receipts --write
orgos ingest classify --write
orgos ingest post --batch <batch_id> --write
```
