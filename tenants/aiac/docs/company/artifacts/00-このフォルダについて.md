# 会社イベント — 出力書類 artifacts/

**正本:** [steward/rules/company-events-layout.md](../../../../steward/rules/company-events-layout.md)

## 役割

イベントに紐づく **生成 MD · 提出ひな形 · 索引** を月次で保管します。経緯は `../events/` の EVT MD を参照してください。

## 構成

```
artifacts/
├── 00-このフォルダについて.md
└── {YYYY-MM}/
    └── EVT-{YYYYMMDD}-{kind}-{slug}/
        ├── 00-artifact-index.md    # 書類一覧
        ├── *.md                    # 生成書類
        └── records/                # PDF/scan（L2 · gitignore）
```

## 命名

| 種別 | ファイル |
|------|---------|
| 索引 | `00-artifact-index.md` |
| 書類 MD | `{種別}-kebab.md` |
| PDF | `records/{YYYYMMDD}-{label}.pdf` |

## 関連

- イベント記録: `../events/{YYYY-MM}/EVT-….md`
- 登記 module: `operations corporate prepare --write` → 本フォルダ配下を推奨
