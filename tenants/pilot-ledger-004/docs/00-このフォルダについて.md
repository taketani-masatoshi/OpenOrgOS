# docs/ — 人向け書類（テナント雛形）

**論理パス:** Agent · CLI ログの `docs/` は本テナント内を指す。

## 推奨ドメイン

```
docs/
├── company/       法人 · 規程 · HR · governance · licenses · tax · events/ · artifacts/
├── contracts/     契約書 MD
├── procurement/   調達 · 受領見積 · 発注書
├── sales/         提出見積
├── finance/       経理 · 請求書
├── io/            inbox / outbox（外部受領・送付控え）
├── legal/         法務メモ
├── exports/       CSV（steward sync all）
├── properties/    物件別 operations/
├── executive/     秘書向け
└── reports/       CLI 生成
```
