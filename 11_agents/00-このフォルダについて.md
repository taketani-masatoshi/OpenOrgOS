# 11_agents — Agent 定義

Steward OS の **8 Agent**（Executive + 秘書 + 6 部門）。Cursor では `@11_agents/xxx` を参照する。

**4 層:** Steward → **Agent** → Skill → Data

---

## Agent 一覧

| # | Agent | 日本語 | 定義 | 要約・出力先 |
|---|-------|--------|------|-------------|
| 1 | Executive Steward | 経営統括 | [executive_steward_agent.md](executive_steward_agent.md) | `docs/reports/` · `executive-notes/` |
| 2 | Secretary | 秘書 | [secretary_agent.md](secretary_agent.md) | `docs/executive/` |
| 3 | Finance | 財務・計画 | [finance_agent.md](finance_agent.md) | `agent-summaries/finance/` |
| 4 | Contract | 契約管理 | [contract_agent.md](contract_agent.md) | `agent-summaries/contract/` |
| 5 | Property Rental | 番町賃貸 | [property_rental_agent.md](property_rental_agent.md) | `agent-summaries/prop-001/` |
| 6 | Hospitality | 亀沢旅館 | [hospitality_agent.md](hospitality_agent.md) | `agent-summaries/prop-002/` |
| 7 | Compliance | コンプライアンス | [compliance_agent.md](compliance_agent.md) | `agent-summaries/compliance/` |
| 8 | Operations | 業務運用 | [operations_agent.md](operations_agent.md) | `agent-summaries/operations/` |

**境界:** Steward（社内経営 OS）↔ Secretary（社長スケジュール・社外窓口）→ [secretary_steward_boundary.md](../13_rules/secretary_steward_boundary.md)

## 使い方

| やりたいこと | 参照 |
|-------------|------|
| 日次経営・KPI・P0 判断 | `@11_agents/executive_steward_agent.md` + `npm run steward -- dashboard` |
| 社長スケジュール・1-on-1・会食・社外調整 | `@11_agents/secretary_agent.md` |
| 数値・予実・税務・固定資産 | `@11_agents/finance_agent.md` + [12_skills/](../12_skills/) |
| 契約 draft→executed | `@11_agents/contract_agent.md` |
| 番町賃貸 | `@11_agents/property_rental_agent.md` |
| 亀沢旅館運営 | `@11_agents/hospitality_agent.md` |
| 規程・許認可・ISO | `@11_agents/compliance_agent.md` |
| inbox · 書類归档 | `@11_agents/operations_agent.md` |
