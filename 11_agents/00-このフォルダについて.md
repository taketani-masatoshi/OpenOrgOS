## 使い方

1. **日次経営** → `@11_agents/executive_steward_agent.md` + `npm run steward -- dashboard`
2. **数値更新** → Finance Agent + [12_skills/](../12_skills/)
3. **契約** → Contract Agent
4. **番町 / 亀沢** → Property Rental / Hospitality
5. **規程・許認可** → Compliance
6. **inbox** → Operations
