# steward/core/agents — コア Agent 定義

OrgOS の **6 コア Agent** — **Steward Agent（経営統括）** · **Secretary Agent（秘書）** · 4 部門 + **業務 Module Agent**。

**用語:** [docs/org-os/orgos-vocabulary.md](../../../docs/org-os/orgos-vocabulary.md) — **OrgOS = 製品** · **Steward = Agent**（Secretary と同列）· Operator ≠ Agent

**4 層:** OrgOS → **Agent** → Skill → Data
