# 14_prompts — 横断 Orchestrator プロンプト

**Agent ではない** 横断タスク用プロンプト。Executive Steward が委譲するか、ユーザーが直接起動する。

---

## 一覧

| プロンプト | 用途 |
|-----------|------|
| [business_plan_decomposition.md](business_plan_decomposition.md) | 事業計画 → 下位計画分解 |
| [secretary_escalation.md](secretary_escalation.md) | Secretary → Executive → 各 Agent 照会 → 統合回答 |
| [delegate_implementation.md](delegate_implementation.md) | 実装委譲 · Work Order · Agent プロンプト生成 |

---

## 使い方

```
@steward/core/orchestrators/business_plan_decomposition.md

Phase 1 の物件リスク計画を起稿してください。
```

数値 YAML 変更は **Finance Agent** へ委譲する。

管轄外の経営・コンプライアンス依頼は **Secretary Escalation Orchestrator** へ（依頼文コピー不要 · Steward スレッド 1 本）。
