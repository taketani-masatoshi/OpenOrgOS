# steward/core/skills — コア Skill

**コア Agent 専用** Skill 定義。業務モジュール Skill は `steward/modules/{id}/skills/` に配置。

| 項目 | 正本 |
|------|------|
| コア registry | [registry.yaml](registry.yaml) |
| 業務 module registry | `steward/modules/{id}/skills/registry.yaml` |
| 集約ロジック | `src/lib/skill-registry.ts` |

```bash
npm run orgos -- skills list
npm run orgos -- skills run monthly-close
```

CLI 実行 Skill は `runtime: cli` · Cursor 専用は `cursor-only`。
