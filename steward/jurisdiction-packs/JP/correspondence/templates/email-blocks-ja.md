# JP email building blocks（定型）

Secretary / 生成器は、自由文の前に本ブロックを合成する。

## 宛名

```
{full_name} 様
```

組織のみ:

```
{organization_name} 御中
```

## オープナー + 名乗り（初回・またはスレッド初出）

```
お世話になっております。
株式会社{company}の秘書です。
```

## オープナー（同一スレッド2通目以降・名乗り省略可）

```
お世話になっております。
```

## 返信への一文

```
ご返信ありがとうございました。
```

## 結び

依頼・調整:

```
何卒よろしくお願い申し上げます。
```

確定:

```
当日は何卒よろしくお願い申し上げます。
```

## 署名（社名行と「秘書」行の2行 · 同一行不可）

```
株式会社{company}
秘書
```
