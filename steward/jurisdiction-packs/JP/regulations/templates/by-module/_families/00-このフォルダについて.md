# 規程ファミリー（cousin fork）

**正本:** 本フォルダ + `src/lib/regulation-module-contract.ts` の `REGULATION_FAMILIES`

隣接業種で語彙は似ても法的義務が異なるとき、**owner の REG をマージせず** sibling が fork する。

## 追加手順

1. `REGULATION_FAMILIES` にエントリを追加（`sourceRegs` · `ownerModuleIds` · `moduleIdHint` · `draftTemplate`）
2. 本ディレクトリに `{family-id}/FORK-DRAFT.md` を置く
3. sibling モジュールに `regulation_family: { id, role: sibling, do_not_mutate: [...] }`
4. 必要なら sibling 用の新 REG を `catalog.yaml` に採番（例: 化粧品 REG-038）
5. `orgos modules check <sibling>` · `regulation-plan <sibling>` で fork_family を確認
