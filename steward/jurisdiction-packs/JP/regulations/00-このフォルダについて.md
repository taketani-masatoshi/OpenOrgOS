## 会計・税務関連（標準雛形）

| ID | 名称 | binds_to | 役割 |
|----|------|----------|------|
| REG-027 | 経理規程 | core / governance | 記帳 · 月次締め · 決算 · 証憑 |
| REG-005 | 経費精算規程 | core / governance | 経費申請 · 証憑 · 交際費区分 |
| REG-028 | クレジットカード規程 | core / governance | 法人カード |
| REG-031 | 法人税務・申告準備規程 | `jp_tax_corporate` | 法人税等の申告 **準備** |
| REG-032 | 消費税務規程 | `jp_tax_consumption` | 課税区分 · 期間集計 · 還付統制 |
| REG-033 | 適格請求書管理規程 | `jp_invoice_qualified` | インボイス |
| REG-034 | 源泉徴収・法定調書規程 | `jp_withholding_statutory` | 源泉 · 法定調書 |

税務関連規程は **社内手続・引き渡し** を定め、e-Tax / 申告書 XML の提出そのものは人間又は税理士の権限とする（条文で明示）。

テナントで有効化するには `regulations.yaml` で `enabled: true` にし、モジュール連動のものは当該モジュールも有効であること。
