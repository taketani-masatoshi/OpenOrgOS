## 会計・税務・リスク領域（標準雛形）

粒度は **モジュール 1:1 ではなくリスク領域**（方針ドキュメント参照）。

| ID | 名称 | binds_to / 領域 |
|----|------|-----------------|
| REG-027 | 経理規程 | core · 記帳·決算·**資金** |
| REG-030 | 組織情報システム権限管理規程 | core · Operator/Wire |
| REG-005 | 経費精算規程 | core |
| REG-010 | 個人情報保護規程 | core · **PII** |
| REG-016 | 内部監査規程 | core/ms · J-SOX 分界（専用 REG なし） |
| REG-031〜034 | 税務系 | 法人税 / 消費税+還付 / インボイス / 源泉 |
| REG-035 | 給与規程 | `jp_payroll` |
| REG-036 | 社会保険手続規程 | `jp_social_insurance` |
| REG-037 | 許認可管理規程 | permit_application / registry / minpaku |

金流・PII を扱うモジュールは manifest の `required_regulations` で連動し、モジュール ON 時は validate **error**。

事業モジュール REG（REG-012 等）の薄い枠は許容。有効テナント業種だけ厚くする。
