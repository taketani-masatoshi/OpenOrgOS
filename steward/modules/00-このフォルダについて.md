# steward/modules — 業務モジュールカタログ

Steward OS **フレームワーク**の業務モジュール定義。テナントが `modules.yaml` で **ON/OFF** し、物件・データパスをバインドする。

## コア Agent vs 業務モジュール

| 種別 | パス | 常時 |
|------|------|------|
| **コア Agent** | [steward/agents/](../agents/00-このフォルダについて.md) | Executive · Secretary · Finance · Contract · Compliance · Operations |
| **業務モジュール** | **本フォルダ** | テナントごとに `enabled: true/false` |

## カタログ

| モジュール id | 日本語 | Agent 定義 | 物件型 |
|---------------|--------|-----------|--------|
| `rental` | 賃貸 | [rental/agent.md](rental/agent.md) | `rental` · `mixed` |
| `hospitality` | 宿泊 | [hospitality/agent.md](hospitality/agent.md) | `hotel` · `mixed` |
| `professional_services` | 受託・サービス | [professional_services/agent.md](professional_services/agent.md) | 非物件（`data_root`） |
| `venture_capital` | ベンチャーキャピタル | [venture_capital/agent.md](venture_capital/agent.md) | 非物件（`data_root` · ファンド/ポートフォリオ） |

## カタログ構成

```
steward/modules/{id}/
├── agent.md          Agent 定義（汎用）
├── skills/           モジュール Skill
└── seed/             雛形データ（YAML · CSV · MD）
```

テナントは `modules.yaml` で **パスをバインド** するのみ。seed は `steward/modules/{id}/seed/` からコピーしてテナント `data/` · `docs/` に展開する。

## テナントでの有効化

```yaml
# tenants/{id}/modules.yaml
modules:
  - id: rental
    enabled: true
    agent: rental
    property_ids: [PROP-001]
    docs_root: docs/properties/PROP-001-minato/operations/
    summary_dir: agent-summaries/rental/
```

```bash
# seed からコピー（例: venture_capital）
cp steward/modules/venture_capital/seed/*.example data/venture-capital/
npm run steward -- modules list
npm run validate
```

## 新モジュール追加手順

1. `steward/modules/{id}/agent.md` を作成（[professional_services/](professional_services/) を雛形）
2. 必要なら `{id}/skills/` に Skill を追加
3. `{id}/seed/` に雛形 YAML · 様式を配置
4. `schemas/modules.ts` の `moduleAgentId` に id を追加
5. テナント `modules.yaml` にエントリ追加（パスバインドのみ）

## 例示

Agent 定義内の物件名・法人名は **架空のサンプル商事**。実テナントは `tenants/{id}/rules/company_context.md` を正とする。
