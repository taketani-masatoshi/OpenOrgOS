# steward/locale — 表示言語（法域と独立）

**正本:** [registry.yaml](registry.yaml) · 実装: `src/lib/locale.ts`  
**言語思想 · 3 層:** [docs/org-os/language-policy.md](../../docs/org-os/language-policy.md)  
**TJS-11 必須言語:** [docs/org-os/tjs-11-target-jurisdictions.md](../../docs/org-os/tjs-11-target-jurisdictions.md) §5

## 2 軸モデル

| 軸 | 設定 | 影響 |
|----|------|------|
| **法域（legal）** | `tenant.yaml` `jurisdiction` | 規程カタログ · 税 schema · 法人形態 |
| **表示（display）** | `display_language` · `locale` | Agent 要約言語 · UI ラベル · 規程 MD 起草言語 |

例: **日本法（JP）+ 英語表示（en）** — デラウェア法人だが日本語 UI も可能（US + ja）。

## CLI

```bash
npm run steward -- locale list
npm run steward -- locale show
npm run steward -- jurisdiction list
npm run steward -- jurisdiction show
```

## 環境変数

`STEWARD_DISPLAY_LANGUAGE=en` — セッションのみ表示言語上書き（法域は変わらない）
