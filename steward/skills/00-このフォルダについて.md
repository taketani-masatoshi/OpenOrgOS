# 12_skills — Skill 定義

Skill は **小さな定型業務単位**。**8 Agent** から呼び出され、限定入力 → 限定出力を返す。

**原則:** Skill を巨大化しない · 経営判断を Skill に持たせない · 複数部門の判断を Skill に持たせない

**実装:** 多くは `npm run steward -- ...`（`src/commands/`）に対応。
