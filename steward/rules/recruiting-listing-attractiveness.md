# 人が動く募集のノウハウ

**版:** 2026-09-20  
**対象:** 採用エージェントが求人票を出す前の自己点検  
**きっかけ:** クラウド基盤・業務委託・1ヶ月・週5日常駐・月額30万円の下書きは、条件を満たす人がほぼ動かない、と評価した。

年齢・性別は書かない。媒体の届き先と、募集条件の中身は別である。

---

## 1. 先に条件、次に文面

書き方を足しても、条件が市場と逆なら人は来ない。点検はこの順にする。

1. 報酬・稼働・場所・期間が、その職種の公開案件と並ぶか
2. 載せる媒体に、その働き方の人がいるか
3. 読んだ人が、自分の1ヶ月を想像できるか

## 2. 今回の下書きに足りなかったもの

正本の下書き: `tenants/_template/data/hr/recruiting/JOB-eng-cloud-1m.md`

| 欠け | なぜ人が動かないか |
|------|-------------------|
| 月額30万円 | 2026年のクラウドエンジニア業務委託は、週5・月140〜180時間で公開案件の中心が月70〜90万円。平均は約79〜80万円（フリーランスボード 2026-02、フリーランススタート 2026-07） |
| 週5・終日常駐 | 同じ2026-02調査で、クラウド案件のフルリモートは約27%、一部リモートは約50%。在宅を含む働き方が約77% |
| 複業クラウドへ出す | 週5の終日は複業の枠と合わない。見る人がいない |
| 1ヶ月だけ | 慣れた人ほど、立ち上がりに見合わない。3ヶ月単位の媒体（Workship、ITエージェント）には最初から載らない |
| クラウドの種類がない | AWS / Google Cloud / Azure のどれか、構築か運用かが無いと、できる人が自分ごとにできない |
| 必須と歓迎が分かれていない | 何ができれば応募してよいか判断できない |
| 精算がない | 準委任の週5は「月140〜180時間で月額いくら、超過・不足の単価」が読み方の標準。固定月額だけだと、残業と欠勤の扱いが不明 |
| 支払いサイトがない | 締め日と支払日が無い |
| 開始日・選考の段取りがない | いつから、何回会うか、返信の目安が無いと動けない |
| 募集主の名称と連絡先がない | フリーランスの募集広告は、名称・住所・連絡先・業務内容・場所・報酬が広告自体に要る（厚生労働省の募集情報の明示）。連絡先は個情をリポジトリに書かず、掲載時に人が足す |
| 週5常駐なのに指揮しない | 読んだ人には雇用に見える。指示が必要なら有期雇用。指示しないなら、稼働上限と成果物で書く |

## 3. 人が動く業務委託の書き方

出典は募集の書き方の実務解説（マイナビサポネット、レバテックの精算幅、Wantedly業務委託の原稿論）と、上の単価調査。

- 題名は「職種＋任せること＋稼働」。例: 「クラウド基盤の設定変更（業務委託・週3・リモート中心）」。「エンジニア募集」だけでは足りない
- 業務の目的と、完了の基準を先に書く。成果物の名前まで書く
- 必須スキルは最小にする。それ以外は歓迎に分ける。年数だけの壁を厚くしない
- 使うクラウドとツールの名前を書く
- 稼働は「週何日・1日の上限・リモートか出社か・定例は何か」まで書く
- 準委任で週4〜5なら、精算幅（目安は140〜180時間）と、超過・控除の単価、固定か月額かを書く
- 報酬は下限を隠さない。幅を書くなら、何で上下するかを書く
- 支払いの締めと支払日を書く
- 選考は段数と、返事までの目安だけ書く
- チームの人数と、誰が範囲を渡すかを書く。日常の指揮命令とは書かない
- 募集主の名称・住所・連絡先・業務内容・場所・報酬を、広告の本文に置く

## 4. 媒体を選ぶときの点検

| 働き方 | 人がいる場所 | 置かない場所 |
|--------|--------------|--------------|
| 1日〜1週間の軽作業 | タイミー、シェアフル、ショットワークス | 業務委託のエンジニア媒体 |
| 1ヶ月までのバイト | バイトル、タウンワーク、バイトな女子 | 週5のエンジニア業務委託 |
| 週2〜3の業務委託 | 複業クラウド、クラウドワークス / ランサーズ | 終日週5の常駐 |
| 週4〜5・3ヶ月以上のエンジニア業務委託 | Workship、ITプロパートナーズ、レバテック。単価は公開相場に合わせる | 月30万円・期間1ヶ月のまま |

女性の応募を増やしたい、20代に届けたい、は媒体の提案にだけ使う。求人票の条件には書かない。職種がエンジニアなら、女性向けバイト媒体に出してもその人は来ない。

## 5. 出してよいか

次が揃うまで、外部には出さない。

- 報酬が、その職種・週の日数の公開相場から大きく下にずれていない。ずらすなら、稼働日数を減らすか、任せる範囲を下げる
- 媒体と働き方が一致している
- クラウド名、成果物、必須スキル、期間、開始時期、精算、支払サイトが書いてある
- 年齢・性別が無い
- 業務委託なのに、毎日の指示と終日席にいることがセットになっていない
