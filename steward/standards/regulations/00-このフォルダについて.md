# steward/standards/regulations — 社内規程テンプレート（フレームワーク）

**ゾーン:** フレームワーク定義 · **対象:** 全テナント共通の規程雛形（会社名・固有名なし）。

テナント固有の **施行文** は `tenants/{id}/docs/company/regulations/` に置く。有効化は `tenants/{id}/regulations.yaml`（正本）· 生成索引 `rules/active_context.md`。

---

## 3 層

| 層 | パス | 内容 |
|----|------|------|
| **カタログ** | [catalog.yaml](catalog.yaml) | REG id · 名称 · binds_to · テンプレパス |
| **テンプレ** | `core/` · `by-module/{id}/` | 雛形 MD（コピー元） |
| **施行文** | `tenants/{id}/docs/company/regulations/` | テナント決議済み規程 |

---

## binds_to（有効化連動）

| type | 意味 | 例 |
|------|------|-----|
| `core` · `governance` | 常時（ガバナンス） | REG-001〜008 |
| `core` · `ms` | 有効 ISO が1つ以上 | REG-016 内部監査 |
| `iso` | 当該 ISO 有効時 | REG-011 ↔ ISO-9001 |
| `iso_any` | いずれか ISO 有効時 | REG-014 ↔ 14001/50001/21401 |
| `module` | 当該モジュール有効時 | REG-012 ↔ hospitality |

**トークン節約:** 無効規程のテンプレ · 施行文は Agent が **読まない**（`active_context` · `.cursorignore`）。

---

## 規程一覧

[catalog.yaml](catalog.yaml) を正とする。Compliance Agent は **有効規程のみ** Primary Read。

---

## テナントでの使い方

1. `catalog.yaml` から必要な REG を選び `regulations.yaml` で `enabled: true/false`
2. 雛形を `docs/company/regulations/` にコピーし会社名・固有名を追記
3. `npm run steward -- modules sync-context`（validate 成功時も自動）
4. モジュール/ISO を OFF にすると紐づく規程は **自動的に読取対象外**
