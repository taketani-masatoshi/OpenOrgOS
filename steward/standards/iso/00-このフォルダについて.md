# steward/standards/iso — ISO 標準テンプレート（フレームワーク）

**ゾーン:** フレームワーク定義 · **対象:** 全テナント共通の ISO 規格説明・方針ドラフト・記録様式。

テナント固有のギャップ評価・監査記録・成熟度は **`tenants/{id}/docs/compliance/iso/`** に置く。本フォルダは **コピー元・参照正本** とし、MAL 等の会社名・物件名は含めない。

---

## 規格一覧

| 規格 | フォルダ | 用途 |
|------|---------|------|
| ISO 9001:2015 | [ISO-9001/](ISO-9001/) | 品質マネジメント |
| ISO/IEC 27001:2022 | [ISO-27001/](ISO-27001/) | 情報セキュリティ |
| ISO 14001:2015 | [ISO-14001/](ISO-14001/) | 環境マネジメント |
| ISO 45001:2018 | [ISO-45001/](ISO-45001/) | 労働安全衛生 |
| ISO 50001:2018 | [ISO-50001/](ISO-50001/) | エネルギーマネジメント |
| ISO 21401:2018 | [ISO-21401/](ISO-21401/) | 持続可能な宿泊施設 |
| ISO 22301:2019 | [ISO-22301/](ISO-22301/) | 事業継続 |
| ISO/IEC 20000-1:2018 | [ISO-20000/](ISO-20000/) | IT サービス管理 |
| ISO 13485:2016 | [ISO-13485/](ISO-13485/) | 医療機器 QMS |
| ISO 22000:2018 | [ISO-22000/](ISO-22000/) | 食品安全 |
| ISO 37001:2016 | [ISO-37001/](ISO-37001/) | 贈収賄防止 |

## 成熟度モデル（共通）

| Level | 意味 |
|-------|------|
| L0 | 未検討 |
| L1 | 方針ドラフト |
| L2 | 方針承認・記録運用開始 |
| L3 | 内部監査・MR 実施記録 |
| L4 | 認証機関審査・登録 |

## テナントでの使い方

1. 対象規格の `00-このフォルダについて.md` と `policy-template.md` を読む
2. 必要な様式を `tenants/{id}/docs/compliance/iso/ISO-XXXX/` にコピーしてカスタマイズ
3. ギャップ評価・監査記録・steward-assessment はテナント側のみ更新
4. Compliance Agent は本フォルダを **Read**、テナント `docs/compliance/iso/**` を **R/W**
