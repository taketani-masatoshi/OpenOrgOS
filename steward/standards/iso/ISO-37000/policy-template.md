# 組織ガバナンス方針（ドラフト）

**準拠参照:** ISO 37000:2021（Guidance）· OrgOS P-01…P-11  
**状態:** draft · **認証:** 本方針は自己宣言の根拠であり、第三者認証を意味しない

## 1. 目的

統治機関は、組織の目的達成に向けた資源の責任ある管理と、説明可能な意思決定を確保する。

## 2. 原則

ISO 37000 の11原則に従う（正本: `steward/rules/governance-principles.md`）。

## 3. 権限と監督

- 権限は役職に紐づけて文書化する。
- 最終承認は人間が行う。LLM / MCP は承認を実行しない。
- 小規模組織では職務分離を補償統制（ログ・兼任禁止）で代替しうる。

## 4. 監督と証跡

- 計画と執行を分離し、予実を比較する。
- 重要例外・承認・危険操作は監査可能な記録に残す。
- 統治機関は統制の有効性を監督する。

## 5. 自己宣言

充足確認: `orgos governance principles status`  
宣言手続: `orgos governance principles init` → 人間署名 → `orgos governance principles declare`
