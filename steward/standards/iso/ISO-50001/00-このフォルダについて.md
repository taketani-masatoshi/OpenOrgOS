# ISO 50001:2018 — エネルギーマネジメント（標準テンプレート）

| 項目 | 内容 |
|------|------|
| **規格** | ISO 50001:2018 |
| **目的** | エネルギー性能の継続的改善 |

---

## 基本方針（ドラフト）

エネルギー使用の把握と改善により、温室効果ガス排出の削減とコスト低減を両立する。

詳細: [policy-template.md](policy-template.md)

---

## エネルギー管理の枠組み

| 要素 | 内容 |
|------|------|
| エネルギー方針 | 経営層の承認 |
| EnPI（性能指標） | kWh/単位、円/単位 等 |
| エネルギー基線 | 比較の基準期間 |
| 目標 | 前年比・絶対値 |
| 設備台帳 | 主要エネルギー使用設備 |
| 購入情報 | 請求書・契約 |
