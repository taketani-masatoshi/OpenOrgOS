# ISO 21401:2018 — 持続可能な宿泊施設（標準テンプレート）

| 項目 | 内容 |
|------|------|
| **規格** | ISO 21401:2018 |
| **種別** | certifiable_ms（HLS · core_profile: hls_full） |
| **目的** | 宿泊施設の持続可能性（環境・社会文化・経済）の管理 |
| **統制** | コア共通11束縛 + 領域統制14件 |

HLS 共通部分（適用範囲・方針・リスク・目標・力量・文書・運用・内部監査・MR・是正）は
[core/](../core/00-このフォルダについて.md) に集約し、本パックは `core_bindings` で条項番号を割り当てる。
本フォルダの `controls` は **宿泊事業に固有のもの** だけを持つ。

---

## 領域統制の構成

本規格の主題である3側面に、ゲスト安全と従業員を加えた5系統。

| 系統 | 統制 |
|------|------|
| **運用** | `CTL-21401-8.1` 宿泊サービスの運用管理 · `CTL-21401-hygiene` 衛生・清掃と委託先監督 |
| **環境** | `env-aspects` 著しい環境側面 · `env-resources` エネルギー・水 · `env-waste` 廃棄物 · `env-purchasing` 環境配慮調達 |
| **社会文化** | `soc-community` 地域関係 · `soc-heritage` 文化・景観 · `soc-protection` 差別禁止と児童保護 · `soc-accessibility` アクセシビリティ |
| **経済** | `eco-local` 地域調達・地域雇用 |
| **ゲスト・従業員** | `guest-safety` 消防・緊急時 · `guest-communication` 情報提供と表示一致 · `worker-welfare` 労働安全衛生 |

**環境訴求の裏づけ。** `guest-communication` は、掲げたサステナビリティの主張に
実測（`env-resources` の KPI）や調達方針（`env-purchasing`）の裏づけがあることを求める。
裏づけのない訴求は本規格が最も嫌う不適合であり、表示の実態一致とあわせて1つの統制で見る。

## §確認事項（規格本文との突合）

**本パックの条項番号は他の HLS 規格の慣行から割り当てたものであり、
ISO 21401:2018 の本文で検証していない。** 認証審査に用いる前に次を確認すること。

| # | 確認対象 | 現在の割当 | 備考 |
|---|---------|-----------|------|
| 1 | 是正処置 | `10.2` | 2018年版 Annex SL では 10.1 の可能性がある |
| 2 | コミュニケーション | `7.4` | `guest-communication` が参照 |
| 3 | 資源 | `7.1` | `worker-welfare` が参照 |
| 4 | 利害関係者 | `4.2` | `soc-community` が参照 |
| 5 | 環境・社会文化・経済の個別要求 | 一律 `8.1` | 本文に細分条項がある場合は分割する |

確認後は `control-map.yaml` の該当 `iso_refs` / `core_bindings` に `verified_on` と
`verified_by` を追記し、`orgos iso maps verify` と `npm test` を実行する。
検証状況は `orgos iso clauses --iso ISO-21401` で一覧できる（既定は全件「未検証」）。

## 記録様式

`templates/` に空の様式を置く。カタログ上 `evidence_forms: complete` — 統制が要求する
証拠ファイルはすべて様式がある。

| ファイル | 用途 | 対応統制 | 着手 |
|---------|------|---------|------|
| `guest-protection-policy.md` | 差別禁止・児童青少年の保護 | `soc-protection` | P1 |
| `worker-welfare.md` | 労働環境・処遇 | `worker-welfare` | P1 |
| `environmental-aspects.csv` | 著しい環境側面の評価 | `env-aspects` | P2 |
| `kpi-log.csv` | 資源使用の月次記録 | `env-resources` · `env-waste` | P2 |
| `risk-opportunities.csv` | リスク及び機会 | コア `risk_approach` | P2 |
| `corrective-actions.csv` | 不適合・是正処置 | コア `corrective_action` | P2 |
| `stakeholder-register.csv` | 近隣・行政・委託先 | `soc-community` | P2 |
| `sustainable-purchasing.md` | 調達基準・供給者評価 | `env-purchasing` | P3 |
| `socio-cultural-plan.md` | 地域文化・景観 | `soc-heritage` | P3 |
| `accessibility-statement.md` | 設備現況の正確な開示 | `soc-accessibility` | P3 |
| `local-economy-log.csv` | 地域調達・地域雇用 | `eco-local` | P3 |
| `guest-communication.md` | ゲストへの周知 | `guest-communication` | P3 |
| `policy-template.md` | サステナビリティ方針 | コア `policy` | P2 |

配置（既存ファイルは上書きしない）:

```bash
orgos --tenant <id> iso templates ISO-21401 --write
```

**空の様式は証拠にならない。** CSV はデータ行が1件以上、Markdown は `{PLACEHOLDER}` を
置換して初めて統制が充足する。

### KPI の検査

```bash
orgos --tenant <id> iso kpi          # 原単位（1人泊あたり）と前月比
orgos --tenant <id> iso kpi --strict # 記入不備があれば exit 1
```

月次の総量ではなく **宿泊人泊あたりの原単位** で評価する。稼働が上がれば総量は増えるため、
総量だけでは改善したか判断できない。

## テナント導入時のチェック

| # | 項目 | 確認ポイント |
|---|------|-------------|
| 1 | サステナビリティ方針 | 承認・周知（コア `policy`） |
| 2 | 著しい側面 | 環境・社会文化・経済の3側面すべてを分析したか |
| 3 | 目的・指標 | 泊数あたりの原単位で設定したか |
| 4 | 法規制一覧 | 旅館業法・消防法・自治体条例 |
| 5 | ステークホルダー | 近隣・行政・ゲスト・委託先・従業員 |
| 6 | 緊急時 | BCP 連携（コア `risk_approach`） |
| 7 | 記録 | 保存期間と改ざん防止（コア `documented_information`） |
| 8 | 着手順序 | `orgos iso audit run` の改善提案は P1 → P3 順。P1 は人の安全・法令要求 |

**参考:** [ISO 21401:2018](https://www.iso.org/standard/67741)
