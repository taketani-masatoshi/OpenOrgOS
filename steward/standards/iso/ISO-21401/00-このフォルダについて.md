# ISO 21401:2018 — 持続可能な宿泊施設（標準テンプレート）

| 項目 | 内容 |
|------|------|
| **規格** | ISO 21401:2018 |
| **目的** | 宿泊施設の持続可能性の管理 |

---

## 基本方針（ドラフト）

宿泊施設は、地域文化・環境に配慮し、ゲスト・地域・従業員の満足を高めながら、資源を効率的に利用する持続可能な宿泊サービスを提供する。

詳細: [policy-template.md](policy-template.md)

---

## 主要テーマ

| テーマ | 管理項目 |
|--------|---------|
| 環境 | エネルギー・水・廃棄物 |
| 社会 | 人権・地域貢献 |
| 経済 | 持続可能な経営 |
| ゲスト | 安全・満足 |
| 従業員 | 安全・研修 |
