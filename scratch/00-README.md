# 作業用スクラッチ（中間試行）

Cursor が試行錯誤するときの**一時置き場**です。gitignore 対象。

## 使い方

| 試行中 | 確定後の移動先 |
|--------|---------------|
| 契約書ドラフト | `docs/contracts/CTR-XXX/` |
| スキャン・原本（未処理） | `docs/io/inbox/` → 処理後 `records/` |
| 印刷用 PDF | `docs/io/outbox/` |
| 計画数値 | `data/plans/` + `docs/exports/*.csv` |
| レポート草稿 | `docs/plans/` または `docs/reports/` |
| 法人書類草稿 | `docs/company/` |

確定したらこのフォルダから削除または移動してください。
