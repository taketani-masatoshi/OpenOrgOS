# 会計方針 — 株式会社MAL

**適用期間:** 第9期（2026/2/1〜2027/1/31）以降  
**正データ:** `cursor/data/finances/` · `cursor/data/plans/`

---

## 1. 会計処理の基準

| 項目 | 方針 |
|------|------|
| 会計基準 | 日本の一般に公正妥当と認められる会計の基準（中小法人想定） |
| 記帳方法 | **発生主義**（収益・費用は発生時点で認識） |
| 現金管理 | 銀行明細・`cash-balance.yaml` で補助。ランウェイ試算は残高確定後 |

**注:** 月次 YAML の一部は予想ベース（forecast）。決算確定時は税理士帳簿を正とし、Steward YAML を同期する。

## 2. 収益認識

| 収益源 | 科目 | 認識基準 |
|--------|------|----------|
| 番町賃貸（PROP-001） | 4100 賃貸料収入 | 賃料発生月（月次100,000円×12） |
| 亀沢宿泊（PROP-002） | 4200 宿泊収入 | 宿泊サービス提供月（2026/8開業以降） |
| その他 | 4900 雑収入 | 個別取引ごと |

OTA 経由の宿泊収入は **売上総額認識**（OTA 手数料は運営費）。入金タイミングと売上計上月のズレは売掛/前受で調整（会計ソフト側）。

## 3. 減価償却

| 資産 | 方法 | 耐用年数 | 備考 |
|------|------|----------|------|
| 番町ハイム312 | 定額法 | 47年 | ASSET-001 · 年353,191円 |
| 亀沢土地 | 非償却 | — | ASSET-002 |
| 亀沢建物 | 定額法 | **TBD** | ASSET-003 · 第9期は0円 |

- 償却開始: 事業供用開始月（番町は取得月、亀沢は税理士確定後）
- 取得原価: 契約書・登記・investment-plan と `fixed-assets.yaml` を一致させる
- 決算整理仕訳: 借方 5100 減価償却費 / 貸方 1290 減価償却累計額

## 4. 役員貸付・借入

- LOAN-001/002 は **無利息役員貸付**（負債科目 2100）
- 法人側は貸付金（1300）と借入金（2100）の表示は税理士指示に従う
- みなし利息・資金調達コストの調整は `tax-profile.yaml` 参照

## 5. 役員報酬

- 第9期: **0円**（`payroll.yaml`）
- 設定時は定時株主総会決議・源泉徴収・社会保険の発生に注意

## 6. 設備投資（CAPEX）

- 資本的支出は `investment-plan.yaml` → `fixed-assets.yaml` に資産登録
- 費用性支出は月次 YAML の repair / other 等へ
- しきい値（少額減価償却資産等）は税理士判断
