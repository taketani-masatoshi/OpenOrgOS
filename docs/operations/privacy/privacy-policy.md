## 1. 基本方針

株式会社MAL（以下「当社」）は、宿泊サービス、翻訳・通訳、業務DX支援等の事業において取得する個人情報を、個人情報保護法及び社内 [個人情報保護規程](../../corporate/regulations/kojin-joho-hogo-kisoku.md)（REG-010）に従い、適正に取り扱います。

## 2. 取得する情報

| 区分 | 例 |
|------|-----|
| 宿泊ゲスト | 氏名、住所、連絡先、国籍、旅券番号、決済情報 |
| お取引先 | 担当者氏名、所属、連絡先、請求情報 |
| 委託先 | 担当者氏名、連絡先、口座情報 |
| 採用応募者（将来） | 履歴書記載事項 |
| Web・問合せ | メールアドレス、IPアドレス、Cookie（利用時） |

## 3. 利用目的

1. 宿泊契約の履行、本人確認、緊急連絡、法令に基づく届出
2. 翻訳・開発等の契約履行、請求、サポート
3. 当社サービスの改善、重要なお知らせ
4. 採用選考・雇用管理（将来）
5. 上記に付随する目的

## 4. 第三者提供

法令に基づく場合を除き、本人の同意なく第三者に提供しません。  
清掃・決済・OTA 等へ委託する場合は、委託先を選定し契約で監督します。

## 5. 外国にある第三者

OTA 等、外国にサーバを置くサービスを利用する場合があります。各サービスのプライバシーポリシーをご確認ください。

## 6. 安全管理

アクセス制限、MFA、最小保管、委託先管理を実施します（[情報セキュリティ管理規程](../../corporate/regulations/joho-security-kanri-kisoku.md)）。

## 7. 開示・訂正・利用停止

ご本人からの請求に応じます。  
**窓口:** info@malkk.com（代表取締役）

## 8. Cookie・解析

当社 Web サイト（malkk.com）で Cookie 又はアクセス解析を導入する場合、サイト上で告知します。

## 9. 改定

改定した場合、当社 Web サイト又は宿泊施設に掲示します。
