## お知らせ

亀沢旅館（株式会社MAL）は、お客様の個人情報を次の目的で利用します。

| 項目 | 内容 |
|------|------|
| **利用目的** | 宿泊契約の履行、本人確認、緊急時連絡、旅館業法に基づく宿泊者記録・外国人宿泊者届出 |
| **記録する情報** | 氏名、住所、職業、年齢、性別、国籍、連絡先、旅券番号（外国籍の方）等 |
| **保管期間** | 宿泊終了後 **最長5年**（法令上必要な期間） |
| **第三者提供** | 法令に基づく届出（警察署等）、清掃・保守委託（必要最小限）を除き提供しません |
| **委託** | 予約プラットフォーム（Airbnb 等）、清掃業者等 |
| **お問合せ** | info@malkk.com |

## 外国籍のお客様へ

旅館業法に基づき、**パスポート等の確認** と **所轄警察署への届出** を行います。  
パスポート画像の保管は **届出に必要な期間** に限り、暗号化された環境で管理します。

## お客様の権利

ご自身の情報の **開示・訂正・利用停止** を請求できます。上記窓口までご連絡ください。
