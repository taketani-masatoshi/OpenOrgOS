# 業務台帳・運用書類（株式会社MAL）

**日常業務の帳簿・名簿・告知文**の置き場です。  
社内規程（REG）の **運用実体** として使います。

| ゾーン | 内容 | Git |
|--------|------|-----|
| `templates/` | 空の様式（ヘッダのみ） | **追跡** |
| `records/` | 記入済みデータ（個人情報含む） | **除外**（`.gitignore`） |
| 告知・規則 MD | プライバシーポリシー等 | **追跡** |

## 運用ルール

1. **記入** — `templates/` をコピーし `records/` に保存（例: `records/2026/宿泊者名簿-2026.csv`）
2. **個人情報** — `records/` はリポジトリに **コミットしない**。バックアップは暗号化 USB 又は限定共有ストレージ
3. **OTA データ** — プラットフォームが原本の場合も、法令で必要な項目は **自社名簿に転記**
4. **雇用時** — [hr/00-このフォルダについて.md](hr/00-このフォルダについて.md) のチェックリストを実施してから `records/` に記入
5. **廃棄** — REG-010 の保管期間経過後、復元不能な方法で削除（REG-007）

## 保管期間（早見）

| 帳簿 | 期間 | 根拠 |
|------|------|------|
| 宿泊者名簿 | 3年（実務）〜5年（個情・税務） | 旅館業法・REG-010 |
| 外国人宿泊者届出控 | 1年 | 旅館業法施行規則 |
| 従業員名簿 | 退職後 **3年** | 労基法 |
| 賃金台帳・出勤簿 | 支払/記録後 **3年** | 労基法 |
| 経理帳簿・証憑 | **7年** | 法人税法 |
| クレーム・清掃記録 | **3年** | REG-012 |
| 日次運営・CI/CO 記録 | **3年** | 運用監査 |
