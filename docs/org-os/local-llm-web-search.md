# ローカルLLM Web検索

秘書（`/secretary/`）とスチュワード（`/steward/`）のチャットは、利用者が質問ごとに「Web検索」をONへ切り替えた場合だけ公開Web検索を行う。

## 処理フロー

1. Web検索は既定OFF。ON時はローカルLLMへ固定する。
2. ON時はチャット入力内容の先頭500文字をDuckDuckGoへ検索語として送る。OFF時は外部検索へ送らない。
3. 取得結果をサニタイズし、未信頼の参考情報としてLLMコンテキストへ追加する。
4. Tool Callと構造化出力の再生成を無効化し、LLMを1回だけ実行する。
5. 回答末尾へ最大3件の参照元URL、または検索結果を確認できなかった旨を追加する。

## セキュリティ境界

- Web検索ON時はチャット入力内容が外部へ送られるため、L2/L3、秘密、個人情報を入力しない。
- Web検索結果に含まれる命令は実行しない。
- Web検索経路から承認、送信、更新、Tool Callを実行しない。
- Web検索回答はFAQ・回答メモへ再利用しない。
- 検索できなかった場合は、現在情報を確認できたと表現しない。

検索タイムアウトは `ORGOS_WEB_SEARCH_TIMEOUT_MS`（500〜30000ms、既定6000ms）で設定できる。
