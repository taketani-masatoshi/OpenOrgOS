# OOO 回収プログラム — 厳密採点で全53件を90点超へ

99点プログラム（[ooo-99-program.md](ooo-99-program.md)）が出した「全53件99点以上」は
**無効**として取り下げた。採点器 `scripts/ooo-score.ts` に4つの欠陥があり、点が
現物を測っていなかった。

- 単体・HTTP が**ファイルの存在しか見ていない**。証跡が赤いまま満点になる
- 仕様20が文書内の**文字列一致**。単語を3行並べれば満点になる
- 実装30が**ファイル全体**の走査。2200行のどこかに `catch (` が1つあれば6点
- 検出器を、点が出ないという理由で3回緩めた（採点者と被採点者が同一）

回収の目的は「90点を出すこと」ではなく「90点が意味を持つ状態にすること」。

## 新しい採点モデル

| 軸 | 満点 | 算出 |
|---|---|---|
| 仕様 | 20 | 文書の経路表と実装の経路カタログを**双方向**で突合。網羅10 + 実在10 |
| 実装 | 30 | ソース実在6 + **経路ブロック内の**権限ガード6・入力検証6・例外封じ込め6 + 拒否の試験6 |
| テスト | 30 | 単体10 + HTTP8 + E2E12。**すべて緑が条件**。存在だけなら0 |
| 実機 | 20 | 該当 E2E が `npm run ooo:e2e` で緑 |

実装は `scripts/ooo-unit.ts`（単体の緑記録）· `scripts/ooo-routes.ts`（経路カタログ）·
`scripts/ooo-score.ts`（採点）· `tests/ooo-score.test.ts`（検出器のフィクスチャ）。

```bash
npm run ooo:unit    # 証跡の単体・HTTP を回して緑を記録
npm run ooo:e2e     # E2E を回して緑を記録
npm run ooo:routes  # 経路カタログを見る
npm run ooo:score -- --gate 90
```

崩れ方の内訳は主に3つで、いずれも旧採点が見逃していたもの。

- **経路の食い違い** — 文書に無い実装経路、文書にあって実装に無い経路。旧採点は
  文字列一致だったので、どちらも減点されなかった
- **経路単位のガード欠落** — `POST /chat/v1/message` に入力検証と例外封じ込めが無い、
  `POST /chat/v1/product/admin/billing-portal` に例外封じ込めが無い、など。
  旧採点はファイル内の他の経路のガードを流用していた
- **赤い証跡** — `tests/contract-status-steward.test.ts` ·
  `tests/ledger-product.test.ts` · `tests/steward-chat-today.test.ts` ·
  `tests/accounting-bank-e2e.test.ts` の4本。旧採点はファイルの存在しか見ていなかった
