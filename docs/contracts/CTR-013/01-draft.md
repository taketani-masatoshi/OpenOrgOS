## 1. 契約の性質

損害保険契約は、保険会社所定の **保険証券（約款＋申込書）** が本体です。本ファイルは **加入前の設計チェックリスト** です。

| 項目 | 内容 |
|------|------|
| 被保険者 | 株式会社MAL |
| 物件 | 番町ハイム312号室（PROP-001） |
| 用途 | 賃貸＋**本社兼用** |
| ステータス | **draft**（証券未保管） |

---

## 2. マンション特有の役割分担

| 対象 | 加入者 | 備考 |
|------|--------|------|
| 建物本体（共用部・専有部分の構造） | 所有者 / 管理組合 | MAL は区分所有者か要確認 |
| 内装・什器備品 | **MAL（テナント保険）** | デスク・PC等 |
| 借家人賠償 | **MAL** | 貸主・管理組合への賠償 |
| 施設賠償 | 任意 | 来訪者への賠償 |

---

## 3. 加入すべき補償（目安）

| 補償 | 目安額 | 必須度 |
|------|--------|:------:|
| **借家人賠償責任** | **1,000万〜2,000万円** | ◎ |
| 什器備品 | 内装・備品評価額 | ○ |
| 施設賠償責任 | 1,000万円〜 | △（来訪者あり） |
| 火災・水濡れ（家財） | 備品評価額 | ○ |

※ 賃貸借契約（CTR-003）・管理規約の **加入義務条項** を確認すること。

---

## 4. 契約書に盛り込む条項（賃貸借・管理側）

貸主指定の保険会社 **強制は原則不可**（独占禁止法）。以下の **補償条件指定** が適正:

```
借主は、借家人賠償責任保険（保険金額○○万円以上）に加入し、
契約開始日から保険期間満了まで、貸主に対する直接請求権（代位求償）
を有する保険証券写しを提出する。
```

---

## 5. 加入フロー

1. 管理組合規約・CTR-003 の保険条項確認
2. 保険代理店で **テナント向け火災保険 / 企業総合** を見積
3. 証券 PDF を `02-executed.md` または `docs/corporate/` 配下に保管
4. YAML `status: executed`、`executed_date`、保険会社名・証券番号を記録
