# 清掃業務委託契約書（亀沢旅館）

> **契約ID:** CTR-012  
> **版:** v0.1（ドラフト）  
> **参考:** [コザクラ行政書士事務所 — 民泊清掃委託](https://kozakur-contract.tokyo/seisou/)、[国土交通省 住宅宿泊管理受託標準契約書](https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/const/tochi_fudousan_kensetsugyo_const_tk3_000001_00049.html)、[民泊学校 清掃契約ガイド2026](https://minpakugakko.com/minpaku-contract-template-2026/)

株式会社MAL（以下「**甲**」という。）と、**TBD（清掃業者名）**（以下「**乙**」という。）とは、甲が乙に清掃業務を委託し、乙がこれを受託することについて、以下のとおり業務委託契約（以下「**本契約**」という。）を締結する。

---

## 第1条（契約の性質）

本契約は、乙が甲のために第2条所定の業務を遂行する**準委任契約**とする。

## 第2条（業務内容）

乙が行う業務（以下「**本件業務**」）は次のとおりとする。

1. **通常清掃** — リビング・寝室・キッチン・浴室・トイレ・玄関等の清掃（掃除機・雑巾掛け・ゴミ回収・消臭）
2. **リネン交換** — シーツ・タオル等（甲支給品または乙持込の別紙定義）
3. **消耗品補充** — トイレットペーパー・アメニティ等（別紙リスト）
4. **完了報告** — 清掃完了後 **30分以内** に **写真付き** 報告（LINE / メール / 専用フォーム）
5. **チェックリスト** — 別紙「清掃チェックリスト」に従う

### 対象施設

| 項目 | 内容 |
|------|------|
| 名称 | 亀沢旅館（1棟貸し） |
| 所在地 | 東京都墨田区亀沢1 |
| タイプ | 一軒家・最大7名 |

### 対応時間

チェックアウト後 **4〜6時間以内** に清掃完了し、次チェックインに備える。

## 第3条（委託料）

| 項目 | 内容 |
|------|------|
| 基本料金 | **12,000円 / 回**（税別） |
| 支払期日 | 毎月末締め、**翌月末日** 振込 |
| 振込手数料 | 甲負担 |
| 追加料金 | 特殊清掃・深夜対応・リネン追加は **事前見積** し甲乙書面（LINE含む）合意 |

※ 電磁的方法（LINE等）による追加料金合意を正式な合意とする（第3条2項）。

## 第4条（再委託）

乙は、甲の事前書面承諾なく本件業務を第三者に再委託してはならない。

## 第5条（鍵・入退室）

1. 甲は乙に施設鍵（またはスマートロックコード）を貸与する。
2. 乙は本件業務以外の目的で施設に立ち入ってはならない。
3. 鍵紛失時は直ちに甲に報告し、必要な措置費用を乙が負担する。

## 第6条（品質・検査）

1. 甲は清掃完了報告後 **24時間以内** に確認する。問題があれば乙に再清掃を求められる。
2. 再清掃費用は乙負担とする（甲の指示不備を除く）。

## 第7条（損害賠償）

乙の故意又は重過失により甲又は第三者に損害が生じた場合、乙はこれを賠償する。備品破損時は **48時間以内** に報告する。

## 第8条（秘密保持・個人情報）

1. 乙は、ゲスト情報・施設レイアウト・鍵情報等を第三者に漏洩してはならない。
2. 契約終了後も **2年間** 秘密保持義務を負う。

## 第9条（契約期間・解約）

| 項目 | 内容 |
|------|------|
| 開始日 | **2026年8月1日** |
| 期間 | **1年**（自動更新。更新前 **30日** 前までに書面解約可） |
| 即時解約 | 重大な品質不良・秘密漏洩時 |

## 第10条（準拠法）

日本法。管轄: **東京地方裁判所**。
