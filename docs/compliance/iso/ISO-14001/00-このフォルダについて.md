# ISO 14001 — 環境マネジメント

| 項目 | 内容 |
|------|------|
| **規格** | ISO 14001:2015 |
| **優先度** | 中 |
| **Maturity** | **L0→L1** |
| **スコープ案** | 亀沢旅館運営、番町本社（段階的） |

---

## MAL で必要な理由

- 21401 の **環境要素** と重複するが、14001 は **汎用 EMS** として取引先・入札で認知度高
- 廃棄物・洗濯排水・アメニティプラスチック等の **削減目標** 管理
- スーパーホテル等は 9001 と **14001 セット** 取得例あり

---

## 基本方針（ドラフト）

環境負荷の低減と汚染の予防に努め、資源の効率的利用と法令遵守を通じて、持続可能な事業を推進する。

---

## 環境アスペクト（初期）

| アスペクト | 影響 | 管理策案 |
|-----------|------|---------|
| 電力・ガス | 地球温暖化 | 50001 連携、LED |
| 上下水 | 資源消耗 | 節水機器、清掃頻度 |
| 洗濯・洗剤 | 水質 | 環境配慮洗剤 |
| ゴミ・リサイル | 埋立 | 分別・減量化 |
| アメニティ | プラスチック | 詰替・最小包装 |
| 騒音 | 近隣 | 21401 ステークホルダー |

## 21401 との関係

**21401 取得を目指すなら 14001 単独は後回し可。** 21401 内の環境要求を先に満たし、必要に応じ 14001 を追加。
