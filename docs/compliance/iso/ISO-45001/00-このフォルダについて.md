# ISO 45001 — 労働安全衛生マネジメント

| 項目 | 内容 |
|------|------|
| **規格** | ISO 45001:2018 |
| **優先度** | 中（**雇用開始後に本格化**） |
| **Maturity** | **L0** |
| **スコープ案** | 亀沢旅館の清掃・運営、将来の従業員 |

---

## MAL で必要な理由

- 現状 **従業員0** → 緊急度は低い
- 清掃 **委託先（CTR-012）** の安全は発注者責任
- 雇用（フロント・清掃スタッフ）時に **労災・安全** 体系が必要

---

## 基本方針（ドラフト）

従業員及び委託先作業者の **安全と健康** を最優先し、危険を除去・低減する。法令を遵守し、労働安全衛生リスクを継続的に改善する。

## 委託清掃（現時点でできること）

- CTR-012 に **安全衛生・保険** 条項を明記（済: 損害賠償）
- 清掃業者の **原状回復・事故報告** フロー
- 21401 の「従業員・委託先」要件と整合
