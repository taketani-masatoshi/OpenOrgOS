# ISO 22301 — 事業継続マネジメント（BCMS）

| 項目 | 内容 |
|------|------|
| **規格** | ISO 22301:2019 |
| **優先度** | 中 |
| **Maturity** | **L0→L1** |
| **スコープ案** | 亀沢旅館の予約・チェックイン継続、本社経営機能 |

---

## MAL で必要な理由

- 停電・災害・PMS 障害で **予約不能・ゲスト対応不能** リスク
- 21401・インバウンド向け **BCP** として説明可能
- 中沢ヴィレッジ事例: クラウド化＋BCP（[ricoh case study](https://www.ricoh.co.jp/magazines/smb/casestudy/006997/)）

---

## 基本方針（ドラフト）

重大な障害発生時も、生命・安全を最優先し、可能な限り宿泊サービスと経営判断を継続する。事前に復旧手順・連絡網を整備する。

## 優先シナリオ

| シナリオ | 目標復旧 | 初期対応 |
|---------|---------|---------|
| PMS/OTA 停止 | 4時間以内に代替連絡 | 電話・メールでゲスト対応 |
| 亀沢停電 | 24時間ゲスト安全確保 | 非常灯・避難経路 |
| 本社 PC 故障 | 48時間経営判断 | 副 PC・クラウド |
