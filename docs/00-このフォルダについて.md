# docs/ — フレームワーク文書

**テナント（会社）の人向け書類は `tenants/{id}/docs/` に置く。** 本フォルダは Steward OS フレームワークの仕様 · 設計のみ。

## 会社データの場所

テナントごとに `tenants/{id}/data/` · `tenants/{id}/docs/` · `tenants/{id}/rules/`。例: [`tenants/mal/`](../tenants/mal/00-README.md)

---

## テナント切替

```bash
export STEWARD_TENANT=mal
npm run steward -- --tenant mal validate
```

論理パス `data/` · `docs/` は CLI · Agent 共通でアクティブテナント内を指す。
