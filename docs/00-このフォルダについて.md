## フォルダ構成

```
docs/
├── io/
│   ├── inbox/         受信トレイ（スキャン・申請書）
│   └── outbox/        出力トレイ（印刷・提出 PDF）
├── company/           法人・規程・HR・許認可
├── finance/           経理・税務・会計テンプレ
├── properties/        物件別運用（PROP-001 番町 · PROP-002 亀沢）
├── compliance/        ISO · 個情
├── contracts/         契約書
├── exports/           YAML から生成する CSV
├── plans/             決算書・予実（MD）
├── executive/         秘書・経営者向けテンプレ
└── reports/           CLI 自動生成 MD
```

## 更新ルール

1. 数値変更 → `data/` YAML → `npm run validate`
2. CSV・MD を同期（`npm run steward -- sync all`）
3. `npm run steward -- report ...` で PDF 再生成
4. 試行中は `scratch/` → 確定後 `docs/` へ
