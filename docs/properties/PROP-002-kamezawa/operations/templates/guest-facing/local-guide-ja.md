# 周辺案内 — 亀沢・両国

**亀沢旅館 · 墨田区**

---

## この街について

**亀沢** は、浮世絵師 **葛飾北斎**（1760年生）の生誕地として知られる、墨田区の歴史ある住宅街です。**北斎通り** の街路灯には作品が掲示され、**すみだ北斎美術館** まで徒歩圏です。両国は **相撲**（両国国技館）と **江戸東京博物館** でも有名で、**スカイツリー**・**浅草** へもアクセス良好です。

| 項目 | 内容 |
|------|------|
| 所在地 | 東京都墨田区亀沢1丁目 |
| 最寄駅 | **都営大江戸線 両国駅** — **徒歩約1分** |
| 出口 | **A3 または A4** → 北斎通り方面 |

---

## 駅からハウスへ

1. 大江戸線 **両国駅** で **A3 / A4 出口**
2. 横断歩道を渡り **北斎通り** 沿い（「両国湯屋 江戸遊」亀沢1-5-8 付近が目印）
3. **徒歩約1分** — 詳細な入室方法はチェックイン案内を参照

JR **総武線 両国駅** 東口からは **徒歩5〜8分**（歩道橋または北斎通り経由）。
