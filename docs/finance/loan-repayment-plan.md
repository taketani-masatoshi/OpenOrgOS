**版:** 2026-06-07 · **正データ:** [`data/plans/debt-plan.yaml`](../../../data/plans/debt-plan.yaml)

## 目的

LOAN-001/002 の返済シミュレーション（基本・保守シナリオ）と年度マイルストーンを管理する。契約上は代表2名協議による任意返済のため、本計画は**目安**であり確定スケジュールではない。

## 返済方針（契約・台帳より）

1. **2025〜2027:** 返済ゼロ（亀沢開業・運転資金優先）
2. **LOAN-001:** 2028年度以降 CF に応じ任意返済 → **2035-01-31** 全額
3. **LOAN-002:** 2030年度以降段階返済 → **2040-01-31** 全額
4. 返済実行時: `loans.yaml` 残高更新 · CTR 返済 MD 記録欄追記
