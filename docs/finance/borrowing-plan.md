# 借入計画（借入計画書）

**版:** 2026-06-07 · **正データ:** [`cursor/data/plans/debt-plan.yaml`](../../../cursor/data/plans/debt-plan.yaml)

## 目的

物件取得に必要な資金の調達方針・借入残高・将来の銀行借入有無を定義し、Executive Steward および Finance Agent の判断基準とする。

## サマリー

| 項目 | 値 |
|------|---:|
| 借入総額 | **112,600,000 円**（1億1,260万円） |
| 借入件数 | 2（LOAN-001 · LOAN-002） |
| 有息負債 | 0 円（全件無利息） |
| 銀行借入（計画） | **0 円** |
| 調達手段 | 役員貸付のみ |

## 調達方針

1. **銀行借入は計画しない** — `business-plan.yaml` の `borrowing_plan: 0` と整合。
2. **物件取得は役員貸付** — 段燕燕・宮城万貴子各50%。利益相反は取締役会承認済み（2026-06-06）。
3. **無利息** — 利息負担なし。返済は元本のみ。
4. **追加調達** — 必要時は本計画・中期事業計画を改定し Executive 承認。
