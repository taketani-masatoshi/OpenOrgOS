## 議事の経過及びその要領

### 第1号議案　金銭消費貸借契約（CTR-008 / LOAN-001）の締結承認

議長は、代表取締役段燕燕及び宮城万貴子が会社に対し、番町ハイム312取得資金 **16,600,000円** を無利息で貸し付ける利益相反取引について説明した。

| 項目 | 内容 |
|------|------|
| 貸主 | 段燕燕・宮城万貴子（各50%持分） |
| 借主 | 株式会社MAL |
| 使途 | PROP-001 取得 |
| 利息 | 0% |
| 返済期限 | **2035年1月31日**（別紙返済計画） |

段燕燕は、当該取引の当事者であるため **本議案の議決に参与せず**、宮城万貴子のみで審議した。

**結果:** 宮城万貴子の同意により、原案どおり承認した。

---

### 第2号議案　金銭消費貸借契約（CTR-009 / LOAN-002）の締結承認

議長は、同貸主が会社に対し、亀沢旅館取得・建築資金 **96,000,000円** を無利息で貸し付ける利益相反取引について説明した。

| 項目 | 内容 |
|------|------|
| 使途 | 土地7,000万円・上置き建築2,600万円相当（PROP-002） |
| 返済期限 | **2040年1月31日**（別紙返済計画） |

宮城万貴子は、当該取引の当事者であるため **本議案の議決に参与せず**、段燕燕のみで審議した。

**結果:** 段燕燕の同意により、原案どおり承認した。

---

### 第3号議案　利益相反取引規程（REG-006）に基づく記録

議長は、上記2件について [利益相反取引規程](../regulations/riekisohan-torihiki-kisoku.md) 第3条に従い、承認内容を本議事録に記載することを確認した。

**結果:** 全員同意。
