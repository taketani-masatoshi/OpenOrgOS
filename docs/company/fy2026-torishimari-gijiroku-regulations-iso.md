## 議事の経過及びその要領

### 第1号議案　ISOマネジメントシステムに基づく社内規程の制定

議長は、[`docs/compliance/iso/steward-assessment.md`](../../compliance/iso/steward-assessment.md) 及び各ISO規格のギャップ分析に基づき、マネジメントシステム運用に必要な社内規程8件を制定することを提案した。

#### 制定理由（要旨）

| 規程 | ID | 根拠 |
|------|-----|------|
| 情報セキュリティ管理規程 | REG-009 | ISO/IEC 27001 — Steward OS・OTA・取引先データ |
| 個人情報保護規程 | REG-010 | 個人情報保護法、27001、21401（ゲスト情報） |
| 品質管理規程 | REG-011 | ISO 9001 — 翻訳・SES・受託開発 |
| 宿泊運営・サステナビリティ規程 | REG-012 | ISO 21401 — 亀沢旅館 |
| 事業継続・危機管理規程 | REG-013 | ISO 22301 — BCP |
| 環境・エネルギー管理規程 | REG-014 | ISO 14001 / 50001 |
| 安全衛生管理規程 | REG-015 | ISO 45001 — 委託清掃・現場 |
| 内部監査規程 | REG-016 | 全MS共通 — 相互監査・マネジメントレビュー |

各規程のドラフトは [`docs/company/regulations/`](../regulations/) に置き、版 **v1.0** として **2026年6月6日** 付で施行する。

#### 決議事項

1. 上記 **REG-009 〜 REG-016** を制定する。
2. 代表取締役2名を、各規程の **運用責任者** とする（個別の担当分担は各規程に記載）。
3. **REG-016** に基づき、2026年度の内部監査計画を **2026年7月末** までに作成する。
4. ISO各フォルダ（[`docs/compliance/iso/`](../../compliance/iso/)）のチェックリスト・記録様式を、本規程に沿って整備する。

**結果:** 出席取締役全員の同意により、原案どおり可決した。

---

### 第2号議案　既存社内規程（REG-001〜008）の制定時期

議長は、役員報酬・議事・稟議・経費・旅費・利益相反・文書管理の各規程（REG-001 〜 REG-008）が引き続き **ドラフト（v0.1）** である旨を報告した。

- REG-001（役員報酬）は **株主総会** の決議が望ましい。
- REG-002 〜 REG-008 は、**2027年3月15日** 定時株主総会（又はその前の取締役会）での **一括制定** を目指す。

**結果:** 全員同意により、上記方針を確認した。

---

### 第3号議案　マネジメントレビューの実施時期

議長は、[REG-016 内部監査規程](../regulations/naibu-kansa-kisoku.md) に基づき、初回の **マネジメントレビュー** を **2027年2月** の第9期決算確認取締役会において実施することを提案した。

レビュー対象: REG-009 〜 REG-016 の運用状況、21401/27001 目標、インシデント・クレームの有無。

**結果:** 全員同意により承認した。
