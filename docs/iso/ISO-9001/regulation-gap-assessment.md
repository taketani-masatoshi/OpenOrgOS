# ISO 9001:2015 規程ギャップ評価

**評価日:** 2026年6月7日  
**対象:** REG-011（品質管理）、REG-016（内部監査）、REG-007（文書管理）、REG-012（宿泊・関連）  
**評価者:** Steward OS ギャップ分析（規程改定 v1.1 前後）

---

## 総合判定

| 区分 | 改定前 | 改定後（v1.1） |
|------|:------:|:--------------:|
| **規程上の適合** | 部分適合 | **適合（L2）** |
| **運用上の適合** | 非適合寄り | **部分適合** |

規程改定後、ISO 9001 が要求する **維持すべき文書化情報** は REG-011・REG-007・REG-016 でカバーする。  
**保有すべき記録**（監査・MR・不適合・力量・顧客満足等）は様式・フォルダは整備済みだが、**実データの蓄積が未着手** のため、認証審査時は運用証拠が不足する。

### スコープ方針（MAL）

| 領域 | QMS スコープ | 規程 |
|------|-------------|------|
| 翻訳・通訳、SES・受託開発、PMO、Steward OS | **9001 主スコープ** | REG-011 |
| 亀沢旅館（宿泊） | **21401 主管理**、9001 ではゲスト満足・クレームを MR へ連携 | REG-012 → REG-016 |
| 共通 | 文書管理、内部監査、MR | REG-007, REG-016 |

宿泊の **サービス提供プロセス** は REG-012 が詳細を規定。9001 観点の顧客満足・不適合は REG-011 第9条・第8条と REG-012 第5条で接続する。

## 改定で閉じたギャップ

1. **QMS スコープ（4.3）** — サービス主スコープ＋宿泊の位置づけを明文化
2. **品質目標（6.2）** — 測定可能な年次目標と保管場所
3. **リスク・機会（6.1）** — 年1回見直し、記録様式
4. **プロセス（4.4）** — 受注〜改善の流れを規程化
5. **力量（7.2）** — 2名体制向けの最小要求
6. **文書管理（7.5）** — REG-007 に QMS 文書の版管理・維持/保有
7. **MR 入力（9.3）** — REG-016 に品質目標・顧客満足を追加（21401 目標との重複整理）
