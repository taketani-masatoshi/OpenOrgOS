# ISO 9001 — 品質マネジメント

| 項目 | 内容 |
|------|------|
| **規格** | ISO 9001:2015 |
| **優先度** | 高 |
| **Maturity** | **L2**（方針・規程 v1.1・記録様式整備） |
| **スコープ** | 翻訳・通訳、SES・受託開発、PMO、Steward 提供（宿泊は REG-012 連携） |

---

## MAL で必要な理由

- B2B 取引で **ISO 9001 取得有無** が要件になることが多い
- 品質の **再現性**（納期・成果物・クレーム対応）を示す
- 亀沢宿泊は **21401 主管理**、9001 ではゲスト満足・クレームを MR へ連携

---

## プロセス

```
受注 → 要件確認 → 実行 → 納品・検収 → 請求 → フィードバック
         ↑__________________クレーム・改善__________________|
```

宿泊クレームは [REG-012](../../corporate/regulations/shukuhaku-unyo-kisoku.md) → MR へ集約。
