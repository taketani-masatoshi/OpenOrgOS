# ISO 9001 — 品質マネジメント

| 項目 | 内容 |
|------|------|
| **規格** | ISO 9001:2015 |
| **優先度** | 高 |
| **Maturity** | **L0→L1** |
| **スコープ案** | 翻訳・通訳、SES・受託開発、PMO、Steward 提供 |

---

## MAL で必要な理由

- B2B 取引で **ISO 9001 取得有無** が要件になることが多い
- 品質の **再現性**（納期・成果物・クレーム対応）を示す
- 亀沢宿泊品質とは **スコープを分離** 可能（9001 はサービス開発側）

---

## 基本方針（ドラフト）

お客様の要求を正確に把握し、約束した品質・納期でサービスを提供する。プロセスを文書化し、不適合を防止・是正し、継続的に改善する。

## プロセス（案）

```
受注 → 要件確認 → 実行 → 納品・検収 → 請求 → フィードバック
         ↑__________________クレーム・改善__________________|
```

亀沢宿泊は **21401** 側で品質を管理し、9001 スコープ外とする選択肢あり。

---

## ロードマップ

| 時期 | アクション |
|------|-----------|
| 案件発生前 | 方針・スコープ確定 |
| 初受注時 | 顧客満足・不適合記録開始 |
| 売上安定後 | 内部監査 → 認証検討 |
