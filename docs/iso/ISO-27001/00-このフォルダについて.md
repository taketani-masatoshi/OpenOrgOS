# ISO/IEC 27001 — 情報セキュリティマネジメント

| 項目 | 内容 |
|------|------|
| **規格** | ISO/IEC 27001:2022 |
| **優先度** | 高 |
| **Maturity** | **L1**（方針ドラフト） |
| **スコープ案** | 本社 IT、Steward OS、亀沢 PMS/OTA、ゲスト個人情報 |

---

## MAL で必要な理由

- Steward OS に経営・契約・財務データを集約
- OTA 経由で **ゲストの氏名・連絡先** を扱う
- 翻訳・SES 案件で **取引先データ** を預かる可能性
- 取引先から **セキュリティチェックシート** を求められる場面に備える

---

## 基本方針（ドラフト）

株式会社MAL は、情報資産の **機密性・完全性・可用性** を確保し、ステークホルダーの信頼に応える。リスクアセスメントに基づき、適切な管理策を選択・運用し、継続的に改善する。
