# ISO 21401 — サステナブルなホテル・旅館

| 項目 | 内容 |
|------|------|
| **規格** | ISO 21401:2018 |
| **優先度** | 高（**宿泊業専用**） |
| **Maturity** | **L0→L1** |
| **スコープ案** | 亀沢旅館（1棟貸し）の運営・管理 |

---

## MAL で必要な理由

- 宿泊業向け **持続可能性** の国際規格（9001/14001 では代替不可）
- SDGs・インバウンド向け **ブランド** 訴求
- 環境・地域・人権・廃棄物を **一体** で管理するフレーム

参考: [J-VAC ISO 21401](https://iso21401.j-vac.co.jp/)

---

## 基本方針（ドラフト）

亀沢旅館は、地域文化・環境に配慮し、ゲスト・地域・従業員の満足を高めながら、資源を効率的に利用する持続可能な宿泊サービスを提供する。

---

## 主要テーマと MAL 現状

| テーマ | 要求 | 現状 | ギャップ |
|--------|------|------|---------|
| 環境 | エネルギー・水・廃棄物 | 光熱35k/月計上 | 実測・分別未整備 |
| 社会 | 人権・地域貢献 | 墨田区亀沢 | 地域連携未文書化 |
| 経済 | 持続可能な経営 | 予実 YAML あり | 21401 目標未設定 |
| ゲスト | 安全・満足 | OTA レビュー | クレーム手順なし |
| 従業員 | 安全・研修 | **従業員0** | 45001 は雇用後 |
