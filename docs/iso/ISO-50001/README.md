# ISO 50001 — エネルギーマネジメント

| 項目 | 内容 |
|------|------|
| **規格** | ISO 50001:2018 |
| **優先度** | 中 |
| **Maturity** | **L0→L1** |
| **スコープ案** | 亀沢旅館（電気・ガス） |

---

## MAL で必要な理由

- 亀沢 **光熱費 35,000円/月**（高稼働一軒家想定）— 主要コスト
- 21401・14001 の **エネルギー要素** を定量的に管理
- 省エネは **利益率** と SDGs の両方に効く

---

## 基本方針（ドラフト）

エネルギー使用の把握と改善により、温室効果ガス排出の削減とコスト低減を両立する。

---

## エネルギー基線（初期）

| 項目 | 値 | 出典 |
|------|-----|------|
| 亀沢 光熱費 | 35,000円/月 | PROP-002 operating_costs |
| 年間想定 | 420,000円 | 12ヶ月フル稼働時 |
| 電力 kWh | **未計測** | スマートメーター要 |
