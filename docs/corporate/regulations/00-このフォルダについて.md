| ISO/IEC 27001 | REG-009, REG-010 | ISMS + 個人情報 |

| ISO 21401 | REG-012, REG-014, REG-015 | 宿泊サステナ |

| ISO 50001 | REG-014 | エネルギーは REG-014 に統合 |

## なぜ必要か（MAL の文脈）

| 規程 | 関連する実務 |
|------|-------------|
| 役員報酬規程 | 取締役委任契約（CTR-004/005）、FY2026 報酬0円の根拠 |
| 利益相反取引規程 | 役員貸付（CTR-008/009）、自己取引の承認手続 |
| 稟議・決裁規程 | 契約締結・物件投資・支払の権限 |
| 情報セキュリティ | Steward OS、OTA、取引先データ |
| 宿泊運営 | 亀沢旅館、21401、クレーム・清掃 |
| 事業継続 | 停電・PMS障害・災害時のゲスト対応 |
| 内部監査 | 2名体制の相互監査、認証準備 |

## 制定・改定フロー

```
1. ドラフト作成（本フォルダ）
2. 取締役会または株主総会で決議
3. 議事録に「〇〇規程を制定する」旨を記載
4. 本ファイルの「制定日」を更新
5. 印刷・記名押印（社内保管10年）
```

**従業員なし**のため、就業規則・育児介護休業規程等は **現時点では不要**。雇用開始時に別途制定。
