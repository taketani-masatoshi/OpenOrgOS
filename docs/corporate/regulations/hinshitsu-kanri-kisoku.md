# 品質管理規程

**株式会社MAL**  
**規程ID:** REG-011  
**版:** v1.0（制定）  
**制定日:** 2026年6月6日（取締役会決議）  
**関連規格:** ISO 9001:2015

---

## 第1条（目的）

本規程は、翻訳・通訳、SES・受託開発、PMO・コンサルティング、Steward 提供等の **サービス品質** を安定させ、顧客満足と継続的改善を実現する。

## 第2条（適用範囲）

1. **品質マネジメントの対象:** 翻訳・通訳、業務DX支援、ソフトウェア開発・SES、PMO、Steward OS 提供。
2. **対象外（別規程）:** 亀沢旅館の宿泊サービスは [REG-012 宿泊運営・サステナビリティ規程](shukuhaku-unyo-kisoku.md) で管理する。

## 第3条（品質方針）

お客様の要求を正確に把握し、約束した **品質・納期** でサービスを提供する。プロセスを文書化し、不適合を防止・是正し、継続的に改善する。

## 第4条（組織・責任）

| 役割 | 担当 |
|------|------|
| 品質責任者 | 代表取締役（段燕燕） |
| 品質管理担当 | 代表取締役（宮城万貴子） |

## 第5条（受注・要求事項のレビュー）

新規受注時は、次を確認してから着手する。

1. 納期・成果物・言語・形式
2. 機密情報・個人情報の取扱い（[REG-010](kojin-joho-hogo-kisoku.md)）
3. 外注の要否（[CTR-001](../../contracts/CTR-001/02-executed.md) 等）
4. 見積・契約条件（[REG-004](ringi-kessai-kisoku.md)）

口頭受注の場合も、メール又はチャットで **要求事項を記録** する。

## 第6条（実行・納品）

1. 翻訳・開発成果物は、納品前に **自己チェック** を行う。
2. ソースコードは Git で版管理し、変更履歴を残す。
3. 納品時は、顧客が検収できる形式（ファイル、リポジトリ、報告書）で提供する。

## 第7条（外注・供給者管理）

1. 外注先は契約台帳に登録する。
2. 初回又は重要な外注は、能力・納期・秘密保持を確認する。
3. 評価記録は [`docs/iso/ISO-9001/`](../../iso/ISO-9001/) に残す。

## 第8条（不適合・クレーム）

1. **不適合:** 要求未達、誤訳、バグ、納期遅延等。
2. 不適合又はクレームを受けた場合、**7日以内** に原因を記録し、是正措置を実施する。
3. 記録様式: [`docs/iso/ISO-9001/`](../../iso/ISO-9001/)（不適合・クレーム台帳）
4. 再発防止が必要な場合は、プロセス又はチェックリストを改定する。

## 第9条（顧客満足）

1. 案件完了後、可能な範囲でフィードバックを取得する。
2. 結果は年次マネジメントレビュー（[REG-016](naibu-kansa-kisoku.md)）で検討する。

## 第10条（改定）

本規程の改定は、取締役会の決議による。
