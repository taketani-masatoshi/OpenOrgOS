# 文書管理規程

**株式会社MAL**  
**規程ID:** REG-007  
**版:** v1.0（制定）  
**制定日:** 2027年3月15日（株主総会決議）

---

## 第1条（目的）

本規程は、会社の書類・データの作成、保管、廃棄について定める。

## 第2条（保管場所の原則）

| 種類 | 保管場所 | 形式 |
|------|---------|------|
| **受信（未処理）** | [`docs/inbox/`](../../inbox/00-このフォルダについて.md) | PDF・画像（**Git 非追跡**） |
| **出力（印刷・提出）** | [`docs/outbox/`](../../outbox/00-このフォルダについて.md) | PDF（**Git 非追跡**） |
| 人が読む書類 | [`docs/`](../../00-このフォルダについて.md) | Markdown・CSV |
| 業務台帳（様式） | [`docs/operations/`](../../operations/00-このフォルダについて.md) | CSV テンプレート |
| 業務台帳（記入済） | `docs/operations/**/records/` | CSV・PDF（**Git 非追跡**） |
| ISO / MS 方針 | [`docs/iso/`](../../iso/00-このフォルダについて.md) | Markdown |
| 正データ・I/O 台帳 | [`cursor/data/`](../../../cursor/data/) | YAML |
| 試行中 | [`cursor/scratch/`](../../../cursor/scratch/) | 任意（確定後移動） |

各フォルダの索引ファイル名: **`docs/` → `00-このフォルダについて.md`**、`cursor/`・`assets/` → **`00-README.md`**（エクスプローラで先頭に並ぶ）。

## 第3条（保管期間）

| 書類 | 期間 |
|------|------|
| 取締役会・株主総会議事録 | **10年** |
| 計算書類・決算書 | **10年** |
| 契約書 | 契約終了後 **10年** |
| 税務関連帳簿・証憑 | **7年**（法人税法） |
| 宿泊者名簿・ゲスト記録 | **5年**（REG-010） |
| 給与関連（将来） | **3年**（労基法） |

## 第4条（契約・規程の管理）

1. 契約は **CTR-XXX**、社内規程は **REG-XXX** で ID を付与する。
2. 台帳: [契約管理表.csv](../../data/契約管理表.csv)、[regulations/00-このフォルダについて.md](00-このフォルダについて.md)
3. 改定時は版番号・制定日を文書冒頭に記載する。
4. ISO 関連規程（REG-009 〜 REG-016）は [ISO 一覧](../../iso/00-このフォルダについて.md) と整合させる。

## 第5条（電磁的記録）

1. 電子メール・Chat での決裁合意は、稟議・決裁規程の範囲内で有効とする。
2. 重要な合意は、議事録又は契約書に **転記** する。

## 第6条（廃棄）

保管期間経過後の廃棄は、代表取締役の承認を得て行う。個人情報を含む場合は適切な方法で抹消する。

## 第7条（改定）

本規程の改定は、取締役会の決議による。
