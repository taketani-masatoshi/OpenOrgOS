# 顧客業務完走証跡

OrgOS Ledger の最初の顧客業務を、実装の存在だけでなく一つの完走経路として確認するための正本です。

## 対象経路

会社登録 → 初回手動仕訳 → 銀行 CSV のテンプレート取得 → dry-run → 本取込 → 月次締め確認 → AI 提案 → 人間承認、を一つの顧客テナントで完走させます。

自動検証の正本は [`tests/customer-journey-http.test.ts`](../../tests/customer-journey-http.test.ts) です。テストは一時 workspace を作成し、終了時に削除します。実テナントの本文・ledger・秘密情報を使用しません。

## 証跡の区分

| 区分 | 意味 | 現在の証拠 |
|---|---|---|
| 実装済み | API/UI/CLI のコードが存在する | Core の製品コード・ルート実装 |
| 自動検証済み | CI またはローカルの再現可能なテストが通る | `npm run test:customer-journey` |
| 本番実証済み | 隔離された実顧客環境で、人間が完走を確認した | **未記録** |

自動テストが緑でも、本番実証済みには昇格させません。本番実証には、実施日、環境、テナント識別子、実施者、結果、未解決事項を `artifacts/reports/` に記録します。秘密情報や顧客本文は記録しません。

## 実行

```bash
cd Core
npm run test:customer-journey
```

このコマンドは自動検証の状態だけを更新します。顧客テナントへの書込み、本番公開、商用宣言は行いません。
